Q2 객관식 ⭐⭐ 슬라이드 4–5
행렬 A = [[3, 6], [1, 2]] 의 det(A) 값과 그 의미를 올바르게 설명한 것은?
Adet(A) = 12 이므로 두 열벡터가 선형 독립이다.
Bdet(A) = 0 이므로 두 열벡터가 선형 종속이고 역행렬이 존재하지 않는다.
Cdet(A) = 0 이므로 두 열벡터가 선형 독립이고 R²를 완전히 Span한다.
Ddet(A) = 6 이므로 두 열벡터가 선형 종속이다.
정답
B
det(A) = (3×2) − (6×1) = 6 − 6 = 0
det = 0 이면 열벡터들이 선형 종속이고, 역행렬이 존재하지 않습니다. c₂ = [6,2]ᵀ = 2 × c₁ = 2×[3,1]ᵀ 이므로 같은 방향의 벡터임을 확인할 수 있습니다.
Q3 객관식 ⭐⭐ 슬라이드 6
고유값(Eigenvalue) λ = 0 의 의미로 옳은 것은?
A행렬이 그 방향으로 데이터를 3배 팽창시킨다.
B고유벡터 방향으로 데이터를 절반으로 수축시킨다.
C역행렬이 존재하며 정보 보존이 완벽하다.
D그 방향으로 데이터가 완전히 납작해지며 정보 소실이 발생하고 역행렬이 없다.
정답
D
λ = 0 이면 A·v = 0·v = 0 이므로, 그 방향으로 완전히 납작해집니다(정보 소실). 또한 Eigenvalue 중 하나라도 0이면 det(A) = 0 (모든 Eigenvalue의 곱 = det)이므로 역행렬이 존재하지 않습니다.

Q5 객관식 [응용] ⭐⭐⭐ 슬라이드 11·14·22
다음 중 PCA를 적용하기에 가장 부적합한 상황은?
A유전자 발현 데이터 (수천 개의 특성, 샘플 간 상관관계 높음)
B사용자–영화 평점 행렬에서 잠재 요인을 추출하고자 할 때
C얼굴 인식 데이터에서 노이즈를 제거하고 핵심 특징만 추출할 때
D나선형(spiral)으로 분포하는 데이터를 2D로 분리하고자 할 때
정답
D
PCA는 데이터가 선형으로 분포한다고 가정합니다. 나선형(spiral) 구조는 대표적인 비선형 구조로, PCA로는 올바르게 분리할 수 없습니다. 이 경우에는 Kernel PCA, t-SNE, UMAP 등의 비선형 차원 축소 기법이 적합합니다. A·B·C는 PCA가 효과적인 대표 응용 사례입니다.
변형 포인트: 강의의 "PCA 한계 — 선형 가정" 개념을 구체적인 응용 상황 판단 문제로 변형했습니다.
Q6 OX ⭐ 슬라이드 9
공분산 행렬은 대칭 행렬(Symmetric Matrix)이므로, 항상 실수 Eigenvalue를 가진다.
정답
O (참)
공분산 행렬 Σ는 Cov(xᵢ,xⱼ) = Cov(xⱼ,xᵢ) 이므로 대칭 행렬입니다. 대칭 행렬의 핵심 성질: 항상 실수 Eigenvalue를 가지며, 서로 다른 Eigenvalue에 대응하는 Eigenvector들은 서로 직교합니다. 이것이 PCA 주성분들이 항상 직교하는 이유입니다.
Q7 OX ⭐⭐ 슬라이드 18
PCA 기반 차원 축소는 원래 특성(feature)의 의미를 그대로 보존하기 때문에, 의료 분야에서 결과 해석이 용이하다는 장점이 있다.
정답
X (거짓)
PCA 차원 축소의 출력은 원래 특성의 선형 조합인 주성분(PC)입니다. PC는 원래 특성들이 섞인 새로운 축이므로 'PC1이 클수록 ??에 해당한다'고 직관적으로 해석하기 어렵습니다. 의료·금융처럼 해석력이 중요한 분야에서는 원래 특성 선택(Feature Selection)이 더 적합합니다.
Q8 OX [응용] ⭐⭐ 슬라이드 9·22
3×3 행렬에서 Eigenvalue가 {5, 3, 0} 으로 나왔다면, 이 행렬의 determinant는 0이 아니며 역행렬이 존재한다.
정답
X (거짓)
핵심 성질: 모든 Eigenvalue의 곱 = det(A)
det(A) = 5 × 3 × 0 = 0
Eigenvalue 중 하나라도 0이면 det = 0, 즉 역행렬이 존재하지 않습니다. PCA에서 이 방향(λ=0에 해당하는 Eigenvector 방향)은 정보가 전혀 없으므로 제외됩니다.
변형 포인트: "모든 Eigenvalue의 곱 = det(A)" 성질을 구체적 수치로 적용하는 개념 결합형 문제입니다.
Q9 단답형 ⭐⭐ 슬라이드 7
Eigenvalue를 구하기 위해 세우는 방정식 det(A − λI) = 0의 명칭을 한국어로 쓰시오.
정답
특성방정식 (Characteristic Equation)
A·v = λ·v 에서 (A − λI)·v = 0, v≠0이 되려면 (A−λI)가 역행렬이 없어야 하므로 det(A − λI) = 0이라는 특성방정식을 세웁니다. 이 방정식을 λ에 대해 풀면 Eigenvalue를 구할 수 있습니다.

10

Q13 종합판단형 [응용] ⭐⭐⭐ 슬라이드 19·22
PCA 차원 축소와 원래 특성 선택(Feature Selection)을 비교한 다음 설명 중 옳지 않은 것은?
APCA 차원 축소는 새로운 주성분(PC)을 출력하므로 원래 특성의 의미를 직접 해석하기 어렵다.
B원래 특성 선택은 공분산 구조를 활용하기 때문에 PCA보다 항상 정보 보존량이 더 높다.
CPCA 차원 축소는 특성 간 상관관계가 높은 고차원 데이터에서 특히 효과적이다.
D원래 특성 선택은 도메인 지식으로 중요 특성이 이미 알려진 경우 유리하다.

B

변형 포인트: 두 방법론의 특징을 교차 혼용하여 혼동을 유발하는 개념 결합형 오류 선지입니다.
Q14 빈칸추론형 ⭐⭐ 슬라이드 12
다음 문장의 (A)와 (B)에 들어갈 알맞은 단어 조합을 고르시오.

PCA가 묻는 두 가지 질문 — Q1: (A)이 매우 작은 축은 정보가 적으므로 제거한다. Q2: (B)이 큰 두 축은 중복 정보를 담고 있으므로 선형 결합으로 통합한다.
A(A) 공분산, (B) 분산

Q16 계산형 ⭐⭐ 슬라이드 7
행렬 A = [[5, 2], [2, 2]] 의 Eigenvalue를 구하시오. (특성방정식을 이용)
Aλ₁ = 6, λ₂ = 1
Bλ₁ = 5, λ₂ = 2
Cλ₁ = 6, λ₂ = 1
Dλ₁ = 7, λ₂ = 0
정답
A (λ₁ = 6, λ₂ = 1)
① (A − λI) 구성:
[[5−λ, 2], [2, 2−λ]]

② 특성방정식:
det = (5−λ)(2−λ) − 2·2 = 0
= 10 − 5λ − 2λ + λ² − 4 = 0
= λ² − 7λ + 6 = 0

③ 인수분해:
(λ−6)(λ−1) = 0
→ λ₁ = 6, λ₂ = 1

검증: λ₁+λ₂ = 7 = trace([[5,2],[2,2]]) = 5+2 = 7 ✓
λ₁×λ₂ = 6 = det([[5,2],[2,2]]) = 5·2−2·2 = 6 ✓

정답
C — [1/√2, 1/√2]ᵀ
① (A − 5I)·v = 0 대입:
[[4-5, 1], [2, 3-5]] · [v₁,v₂]ᵀ = 0

→ v_norm = [1/√2, 1/√2]ᵀ ≈ [0.707, 0.707]ᵀ

B는 λ₂ = 2에 대응하는 Eigenvector입니다.
변형 포인트: B 선지([2/√5, -1/√5]ᵀ)는 λ₂=2의 정답을 오답 선지로 배치하여 혼동을 유발합니다. λ값과 Eigenvector를 정확히 연결하는 것이 핵심입니다.
Q19 서술형 ⭐⭐⭐ 슬라이드 11·14
PCA(주성분 분석)의 정의와 5단계 절차를 각 단계의 수식과 함께 설명하시오. 각 단계에서 수행하는 작업과 그 필요성도 함께 서술하시오.
채점 기준 — 필수 키워드 (5개)
분산 최대화 표준화 x'=(x-μ)/σ 공분산 행렬 Σ=(1/N)XᵀX Eigenvalue 분해 + 선택 투영 Z=X·W
모범 답안
정의: PCA는 고차원 데이터를 데이터의 분산이 최대인 방향(주성분)으로 투영하여 차원을 축소하는 비지도 학습 기법이다.

① 데이터 표준화: x'ᵢ = (xᵢ − μ)/σ. 특성마다 단위가 달라 스케일 차이가 발생하면 Eigenvalue가 편향되므로, 평균 0·표준편차 1로 통일한다.

② 공분산 행렬 계산: Σ = (1/N)XᵀX. 특성 간 선형 관계(중복 정보)를 수치화한다. Σ는 대칭 행렬이다.

③ Eigenvalue 분해: Σ·vᵢ = λᵢ·vᵢ 를 풀어 {λ₁≥λ₂≥...≥λd}와 {v₁,...,vd}를 구한다. λ가 클수록 데이터가 많이 퍼진 방향이다.

④ 주성분 선택: 누적 분산 설명률(Σλᵢ/Σλ)이 90~95%가 되는 k개의 Eigenvector를 선택한다.

⑤ 데이터 투영: Z = X·W (W: 선택된 k개 Eigenvector 열행렬). 원래 d차원 → k차원으로 변환 완료.
Q20 서술형 [응용] ⭐⭐⭐ 슬라이드 19·22
의료 진단 AI 시스템을 개발하는 팀이 "고차원 환자 데이터에 PCA를 적용하여 차원을 줄인 뒤 질병을 분류"하겠다는 계획을 세웠다. 이 계획의 잠재적 문제점을 2가지 이상 지적하고, 각각에 대한 대안을 제시하시오.
채점 기준 — 필수 키워드 (5개)
해석의 어려움 (Interpretability) 분산≠분류 중요도 Label 정보 미활용 LDA 또는 Feature Selection 대안 비선형 구조 대응 불가
모범 답안
문제 ①: 해석 불가능성 (Interpretability)
PCA의 주성분(PC)은 원래 특성들의 선형 조합이므로 'PC1이 높으면 어떤 특성이 관여한다'고 의료진에게 설명할 수 없다. 의료 AI는 진단 근거를 제시해야 하는 규제 요건이 있어 블랙박스 처리는 부적합하다.
→ 대안: 원래 특성 선택(Feature Selection)을 활용하거나, SHAP 등 설명 가능 AI(XAI) 기법을 병행한다.

문제 ②: 분류 중요 방향 누락 위험
PCA는 분산이 큰 방향을 주성분으로 선택하지만, 분류(질병/정상 구분)에 결정적인 방향이 분산이 작을 수 있다. Label 정보를 전혀 활용하지 않는 비지도 학습 특성상, 분류 정확도가 오히려 저하될 수 있다.
→ 대안: 지도학습 기반 차원 축소인 LDA(Linear Discriminant Analysis)를 사용하면 클래스 간 분리를 최대화하는 방향으로 축소한다.

(선택) 문제 ③: 비선형 구조 미포착
환자 데이터가 비선형 구조로 분포하는 경우 PCA의 선형 가정이 위배된다.
→ 대안: Kernel PCA, UMAP 등의 비선형 차원 축소 기법 사용.
