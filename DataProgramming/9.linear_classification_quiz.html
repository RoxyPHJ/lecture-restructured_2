Q1 객관식 ⭐ 슬라이드 3
선형 모델이 첫 번째 실용적 선택으로 자주 사용되는 근본적인 이유는?
정답
B
선형 모델의 핵심 장점은 낮은 VC 차원이다. VC 차원이 작으면 E_in(훈련 오차)이 E_out(실제 오차)에 가깝게 유지되어 일반화가 보장된다. 선형 모델은 데이터를 완벽히 분리하거나 항상 빠른 것이 아니라, 이 일반화 특성 때문에 첫 번째 선택지로 적합하다.
Q2 객관식 ⭐⭐ 슬라이드 6
이진 분류 가설 h(x) = sign(wᵀx)에서 x₀ = 1로 설정하는 이유는?
정답
C
x₀ = 1로 설정하면 bias w₀를 별도로 처리하지 않고 wᵀx = w₀x₀ + w₁x₁ + ... + w_d·x_d 형태로 통합할 수 있다. 이를 통해 d차원 입력을 d+1차원 벡터로 확장하여 bias를 포함한 선형 연산을 단일 내적으로 표현한다.
Q3 객관식 ⭐⭐ 슬라이드 9
노이즈가 있는 데이터에서 min(1/N)·Σ[sign(wᵀx) ≠ y]를 정확히 최소화하기 어려운 이유는?
정답
B
sign(·) 함수와 오분류 여부를 나타내는 [·] 지시 함수는 모두 불연속(이산) 함수다. 미분이 불가능하므로 gradient 기반 최적화를 쓸 수 없고, 조합론적 최적화 문제가 된다. 이는 일반적으로 NP-hard이며 효율적인 알고리즘이 알려져 있지 않다.
Q4 객관식 ⭐⭐ 슬라이드 11
Pocket Algorithm이 PLA보다 느린 구체적인 이유는?
정답
C
의사코드 Line 4: "evaluate E_in(w(t+1)) — time consuming"이 핵심이다. PLA는 오분류 예제 1개를 찾아 업데이트하면 끝이지만, Pocket은 새로운 w가 기존 pocket보다 나은지 판단하기 위해 전체 N개 예제의 E_in을 매 반복마다 계산해야 한다. 따라서 반복당 O(N) 비용이 추가로 발생한다.
Q5 객관식 ⭐⭐ 슬라이드 20
MNIST 데이터셋에서 분류기 성능을 올바르게 나열한 것은? (오류율 낮은 순)
정답
B
CNN 0.23% < Gaussian SVM 1.4% < Linear 7.6% 순으로 오류율이 낮다. CNN이 가장 우수하고 선형 분류기가 가장 성능이 낮다. 참고로 인간의 E_out은 약 2.5%로 선형보다는 낮지만 CNN보다는 높다.

아래 상황 중 비선형 변환(nonlinear transformation)이 반드시 필요한 경우는?
정답
B
[응용 개념 적용] A는 노이즈형 상황(type a)으로 Pocket Algorithm으로 대응 가능하다. B는 구조적으로 선형 분리가 불가능한 경우(type b)로, 강의에서 "선형 모델이 올바르지 않으며 비선형 변환이 필요하다"고 명시된 유일한 상황이다. C는 일반화 문제(overfitting 또는 분포 변화)이며, D는 VC 차원 정의를 잘못 적용한 선지다.
Q7 객관식 [응용] ⭐⭐⭐ 슬라이드 14–16
손글씨 인식에서 특징 추출(feature extraction)의 목적과 가장 거리가 먼 설명은?
정답
D
[응용 개념 결합] 특징 추출의 목적은 차원 축소와 의미 있는 표현 학습이다(A, B). 잘 선택된 특징은 feature space에서 선형 분리 가능성을 높일 수 있다(C). 그러나 VC 차원은 가설 집합(hypothesis set)의 복잡도를 나타내는 것으로, 특징 추출 자체가 VC 차원을 높이는 것은 아니다. 오히려 차원 축소는 일반화에 유리한 효과를 준다.

Q11 OX ⭐⭐ 슬라이드 9
E_in 최소화 문제가 NP-hard인 이유는 입력 데이터의 차원 d가 지수적으로 크기 때문이다.

Q12 OX [응용] ⭐⭐⭐ 슬라이드 8, 10
노이즈가 있는 데이터(type a)에서 Pocket Algorithm으로 학습하면, 최종 E_in이 반드시 0이 된다.
O
X
정답
X (거짓)
[응용 조건 변형] Pocket Algorithm의 목표는 E_in을 0으로 만드는 것이 아니라 "근사적으로 최소화(approximately minimize)"하는 것이다. 노이즈 데이터는 선형으로 완벽 분리가 불가능하므로 E_in = 0은 달성할 수 없다. 강의에서 "output a hypothesis with a small E_in (not necessarily 0)"라고 명시한다. 실험에서도 Pocket의 E_in = 0.45%로 0이 아닌 값이다.
03 · 단답형
Q13 단답형 ⭐ 슬라이드 3
학습 모델의 표현 용량(capacity)을 측정하는 지표로, 이 값이 작을수록 E_in → E_out 일반화가 잘 된다. 이 지표의 이름은?
정답
VC 차원 (Vapnik-Chervonenkis dimension, d_VC)
VC 차원은 학습 모델(가설 집합)이 데이터를 얼마나 다양하게 표현할 수 있는지를 나타내는 지표다. 작은 VC 차원은 모델의 복잡도가 낮음을 의미하며, E_in과 E_out의 차이를 작게 유지하는 일반화 보장의 근거가 된다.
Q14 단답형 ⭐ 슬라이드 10
Pocket Algorithm을 처음 제안한 연구자의 이름과 제안 연도를 쓰시오.
정답
Gallant, 1990
슬라이드 10에서 "Pocket algorithm with ratchet (Gallant, 1990)"이라고 명시되어 있다. 정식 명칭은 "Pocket algorithm with ratchet"이며, ratchet는 역진 방지 기어로 최선의 w를 한 방향으로만 갱신(절대 악화되지 않음)하는 특성을 은유한다.

06 · 계산형
Q23 계산형 [응용] ⭐⭐⭐ 슬라이드 18
훈련 데이터 N = 2000개에 대해 Pocket Algorithm을 T = 500회 반복 실행한다고 가정한다.

• PLA의 반복당 비용: O(1) (오분류 예제 1개 업데이트)
• Pocket의 반복당 추가 비용: O(N) (E_in 전체 평가)

T회 수행 기준으로, Pocket의 총 E_in 평가에 소요되는 연산 횟수는?
정답
C — 1,000,000회
[응용 — 계산형]
T = 500회, N = 2000개 매 반복마다 전체 N개 예제 평가: 500 × 2,000 = 1,000,000회 따라서 E_in 평가 총 연산 횟수 = T × N = 1,000,000 (PLA는 T = 500회 업데이트만 수행 → 500회)
이것이 Pocket이 PLA보다 N배(= 2000배) 느린 이유다. T를 고정할 때 N이 클수록 Pocket의 비용은 선형으로 증가한다.

Q24 서술형 ⭐⭐⭐ 슬라이드 8–11

• "PLA를 반복하면 된다"고만 쓰고 pocket에 보관하는 핵심 아이디어를 누락한 경우

노이즈 데이터에서의 E_in 최소화 문제는 sign(·)과 오분류 지시함수 [·]가 모두 이산 함수이므로, 목적 함수가 미분 불가능한 조합론적 최적화 문제가 된다. 이는 일반적으로 NP-hard로, 효율적인 정확 해법이 존재하지 않는다. Pocket Algorithm은 이를 근사적으로 해결하기 위해 PLA 업데이트를 유지하면서, 매 반복 후 전체 데이터로 E_in을 평가하여 지금까지 가장 E_in이 낮은 w를 pocket에 보관한다. 이를 통해 알고리즘이 종료될 때 가장 우수한 w를 최종 가설로 반환한다.
Q25 서술형 ⭐⭐⭐ 슬라이드 14–19
손글씨 숫자 인식 예제에서 사용된 두 가지 해결 전략(다중 클래스 분해 + 특징 추출)의 필요성을 각각 설명하고, 두 전략이 결합되었을 때 선형 분류기 적용이 가능해지는 이유를 서술하시오.
채점 기준 키워드
① 이진 분해  ② 다중→이진  ③ 특징 추출  ④ 차원 축소  ⑤ feature space 선형 분리 가능
감점 요인
• 특징 추출의 이점을 "빠르다"로만 서술하고, feature space에서 선형 분리 가능성이 높아짐을 언급하지 않은 경우
• 두 전략의 결합 효과를 서술하지 않고 각각만 나열한 경우

모범 답안
먼저 다중 클래스 분해는, 10개 숫자를 동시에 분류하는 문제를 여러 이진 분류 문제로 나누어 선형 분류기를 적용 가능하게 한다. 이진 분류기는 단순하고 VC 차원이 작아 일반화가 유리하다. 다음으로 특징 추출은, 16×16 = 256차원의 raw 픽셀 대신 intensity(강도)와 symmetry(대칭성)라는 2개의 의미 있는 특징만 사용한다. 이는 인간의 직관적 인식 방식을 반영하며, 고차원 raw space에서는 선형 분리가 어려운 두 클래스가 2차원 feature space에서는 대략적으로 선형 분리 가능한 형태로 배치된다. 두 전략의 결합을 통해, 복잡한 다중 클래스 고차원 문제를 2차원 feature space에서의 이진 분류 문제로 단순화하여 선형 분류기 적용이 가능해진다.
