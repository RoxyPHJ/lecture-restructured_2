h(x) = σ((A) + (B)x₁ + (B)x₂)
A(A) = −10, (B) = +20

Q10 기본 종합판단 ⭐⭐ 보통 slide 19-21
ReLU와 관련한 다음 설명 중 옳지 않은 것은?
AReLU는 logistic sigmoid보다 생물학적으로 더 그럴듯한(plausible) 뉴런 발화 모델이다.
BSoftplus는 ReLU의 미분 가능한(smooth) 근사 함수이며, 그 도함수는 logistic 함수이다.
CReLU는 vanishing gradient 문제를 완전히 제거하므로 학습 도중 뉴런이 죽는(dying) 현상이 발생하지 않는다.
DLeaky ReLU는 음수 구간에 작은 상수 기울기 α를 부여하여 dying ReLU 문제를 완화한다.
정답 및 해설
정답: C
C가 틀렸다. ReLU는 s ≤ 0인 구간에서 기울기 = 0이므로, 학습 중 해당 뉴런이 영구적으로 비활성화되는 "Dying ReLU" 문제가 존재한다. Vanishing gradient를 완화할 뿐 완전히 제거하지 않는다. 이를 해결하기 위해 Leaky ReLU(α 도입)가 제안되었다. A, B, D는 모두 강의에서 명시적으로 서술된 올바른 내용이다.

B약 0.57

정답: C — 약 0.87

Q18 [응용] 계산형 ⭐⭐⭐ 어려움 slide 15, 19
Softplus 함수 σ(s) = ln(1+eˢ)의 도함수 σ'(s)를 s=0에서 계산한 값은?

B0.5
C1
Dln(2)
정답 및 해설
정답: B — 0.5

ReLU와 Leaky ReLU를 비교하시오. 각 함수의 수식, 장단점을 기준으로 서술하고, Leaky ReLU가 제안된 배경을 설명하시오.

※ 서술형 문제는 답안을 작성한 후 아래 '정답/해설 보기' 버튼으로 모범답안을 확인하세요.

채점 기준 키워드
필수 키워드: max(0,s) · Dying ReLU · 기울기 0 · αs (α 소상수) · vanishing gradient 완화 · 생물학적 타당성
모범 답안
ReLU: σ(s) = max(0,s). 입력이 양수면 그대로 출력, 음수면 0. 장점: ① 기울기가 상수(1)로 전파되어 vanishing gradient 완화 ② 계산 효율 높음 ③ 생물학적으로 더 타당. 단점: 입력이 0 이하인 구간에서 기울기=0이므로, 해당 뉴런이 학습 도중 영구적으로 비활성화되는 "Dying ReLU" 문제 발생.

Leaky ReLU: σ(s) = s (s>0), αs (s≤0), α ≈ 0.01. Dying ReLU 문제를 해결하기 위해 음수 구간에 작은 기울기 α를 부여하여, s≤0에서도 기울기가 0이 되지 않도록 함. 장점: Dying ReLU 방지. 단점: α를 하이퍼파라미터로 설정해야 하며 최적값이 데이터에 따라 다름.

※ 논술형 문제입니다. 작성 후 모범답안을 확인하세요.

채점 기준 키워드 (5개)
feature detector · distributed representation · nonlinear transformation · feature space · 층수↑→표현력↑ 학습난이도↑
모범 답안
MLP의 각 은닉층은 distributed representation에 대응하며, 은닉 뉴런들은 feature detector로 기능한다. 구체적으로, 은닉 뉴런은 입력 데이터를 비선형 활성화 함수를 통해 feature space로 비선형 변환하고, 이 과정에서 학습 데이터의 유의미한 특징을 점진적으로 발견한다. 층이 깊어질수록 저수준(엣지·색상) → 중수준(부분 패턴) → 고수준(의미적 개념)으로 추상화 수준이 높아지는 계층적 표현이 형성된다.

은닉층 수 증가의 장점: 표현력 증가(비선형 경계의 복잡도 향상), 더 추상적인 피처 학습 가능, 더 어려운 패턴 인식 과제 해결 가능. 단점: 학습 난이도 증가(vanishing gradient, 최적화 어려움), 과적합 위험, 연산 비용 증가. 이를 위한 실용적 해결책(BatchNorm, Dropout 등)이 존재한다.
