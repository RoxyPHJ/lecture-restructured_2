신경망의 신호 유형

Function Signal 순전파 신호
  • 입력에서 신호가 들어옴
  • 네트워크를 순방향으로 전파
  • 출력에서 결과값이 나옴
Error Signal 역전파 신호
  • 출력 뉴런에서 오차가 발생
  • 네트워크를 역방향으로 전파
  • 가중치 업데이트에 사용
순전파 vs 역전파 신호 흐름
02

가정 & 표기법

네트워크 구조

d − H − K 신경망

  • d: 입력 차원 수
  • H: 은닉층 유닛 수
  • K: 출력 신호 수
  • 단일 은닉층 feedforward 네트워크 (일반성 손실 없음)
표기법 (Notation)
기호의미차원
x입력 벡터ℝᵈ
z은닉층 활성화ℝᴴ
h출력 벡터ℝᴷ
w_ji입력→은닉 가중치—
w_kj은닉→출력 가중치—
d − H − K 네트워크 구조도
활성화 함수 (Activation Functions)
은닉 유닛 활성화
z_j(x) = σ( Σᵢ w_ji · xᵢ )
출력 유닛 활성화
h_k(x) = σ( Σⱼ w_kj · z_j ) = σ( Σⱼ w_kj · σ(Σᵢ w_ji · xᵢ) )
03

오차 측도 (Error Measures)

오차 신호 eₖ
eₖ ≜ hₖ − yₖ

NN 출력과 정답 레이블의 차이

샘플 오차 ℰₙ
ℰₙ = ½ Σₖ eₖ,ₙ² = ½ ‖hₙ − yₙ‖²

n번째 샘플의 제곱 오차 합

평균 제곱 오차 ℰ_D
ℰ_D = (1/N) Σₙ ℰₙ = (1/2N) Σₙ Σₖ eₖ,ₙ²

전체 데이터셋 평균 오차

학습 목표 (Learning Objective)
w* = argmin_w (1/N) Σₙ ℰₙ(w)

비볼록(Non-convex) 최적화 문제 → 전역 최솟값 보장 어려움

모델이 매우 복잡 → 많은 학습 데이터 필요, Hessian 행렬이 매우 큼

04

최적화 방법 선택

비추천 2차 기법 (e.g., Newton's method)
  • 수렴 속도는 빠름
  • Hessian 행렬이 매우 커질 수 있음
  • 신경망에는 부적합
추천 1차 온라인 기법 (SGD)
w ← w − η · ∇ℰ(w)
  • 반복적 최적화
  • 온라인(순차) 또는 배치 최적화 모두 가능
  • 핵심: 오차 기울기 ∇ℰ 계산 → 역전파로 해결
05

역전파 알고리즘 개요

역전파 (Backpropagation, Backprop)
  • 다층 퍼셉트론에서 ∇ℰ(w)를 효율적으로 계산하는 방법
  • "오차의 역방향 전파(back propagation of errors)"를 의미
  • 1980년대 중반 신경망의 획기적 발전: 다층 퍼셉트론을 계산적으로 효율적으로 학습
Phase 1 순전파 (Forward Phase)
  • 1입력 x를 네트워크에 적용
  • 2모든 은닉/출력 유닛의 활성화값 계산
Phase 2 역전파 (Backward Phase)
  • 1시냅스 가중치를 순차적으로 조정
  • 2출력층: 직접적인 오차 신호 → 계산 쉬움
  • 3은닉층: 직접적 교사 신호 없음 → 어려움
Credit Assignment Problem (신용 할당 문제)

출력층: 명시적 타겟 yₖ가 존재 → eₖ = hₖ − yₖ로 직접 계산 가능. 민감도 ∂ℰ/∂wₖⱼ 계산이 쉬움.

은닉층: 각 은닉 유닛의 출력이 어떠해야 하는지 알려주는 교사가 없음. 민감도 ∂ℰ/∂wⱼᵢ 계산이 어려움 → 역전파의 힘으로 해결!

06

출력층 역전파 (Backward Phase: Output Layer)

Chain Rule 복습
∂f/∂x = (∂f/∂g) · (∂g/∂x) ↑ 외부함수 미분 ↑ 내부함수 미분
출력층: 민감도 인자 & 델타 오차

민감도 인자 (Sensitivity Factor)
∂ℰ/∂wₖⱼ
가중치 wₖⱼ에 대한 가중치 공간에서의 탐색 방향 결정

델타 오차 (Delta Error) δₖ
δₖ = ∂ℰ/∂sₖ
유닛의 활성화 sₖ에 따른 ℰ 변화를 기술

Chain Rule 적용 (출력층)
민감도: ∂ℰ/∂wₖⱼ = (∂ℰ/∂sₖ) · (∂sₖ/∂wₖⱼ) = δₖ · zⱼ 델타 오차: δₖ = ∂ℰ/∂sₖ = (∂ℰ/∂eₖ)·(∂eₖ/∂hₖ)·(∂hₖ/∂sₖ) = eₖ · σ'(sₖ)
출력층 핵심 요약 (Output Layer Summary)
민감도 인자
∂ℰ/∂wₖⱼ = δₖ · zⱼ
= (델타 오차) × (입력 신호)
델타 오차
δₖ = eₖ · σ'(sₖ)
eₖ = hₖ − yₖ (명시적 오차 신호)
가중치 갱신 (Delta Rule)
Δwₖⱼ = −η · δₖ · zⱼ
w ← w + Δw
Delta Rule 구조 (순전파 vs 역전파)
07

은닉층 역전파 (Backward Phase: Hidden Layer)

은닉층: 명시적 오차 신호 없음

Credit Assignment Problem: 은닉 유닛의 출력이 무엇이어야 하는지 알려주는 명시적 교사가 없음 → ∂ℰ/∂wⱼᵢ 계산이 어려움

역전파의 힘: 각 은닉 유닛에 대한 유효 오차(effective error)를 계산할 수 있음 → 은닉층 가중치 갱신 규칙 유도 가능

은닉층 델타 오차 유도
민감도 인자
∂ℰ/∂wⱼᵢ = (∂ℰ/∂sⱼ) · (∂sⱼ/∂wⱼᵢ) = δⱼ · xᵢ
델타 오차 δⱼ (핵심!)
δⱼ = ∂ℰ/∂sⱼ = (∂ℰ/∂zⱼ) · (∂zⱼ/∂sⱼ) = σ'(sⱼ) · Σₖ wₖⱼ · δₖ ↑ 출력층의 δₖ를 역방향으로 전파!
유도 과정 요약
δⱼ = ∂ℰ/∂sⱼ = (∂ℰ/∂zⱼ) · σ'(sⱼ) = [Σₖ eₖ · ∂eₖ/∂zⱼ] · σ'(sⱼ) = [Σₖ eₖ · σ'(sₖ) · wₖⱼ] · σ'(sⱼ) = σ'(sⱼ) · Σₖ δₖ · wₖⱼ

핵심: 은닉층 δⱼ는 출력층 δₖ의 가중합에 σ'(sⱼ)를 곱한 것! 오차가 뒤로 흐름.

은닉층 핵심 요약 (Hidden Layer Summary)
민감도 인자
∂ℰ/∂wⱼᵢ = δⱼ · xᵢ
= (델타 오차) × (입력 신호)
델타 오차 (역전파)
δⱼ = σ'(sⱼ) · Σₖ wₖⱼδₖ
출력층 δₖ를 통해 계산
가중치 갱신
Δwⱼᵢ = −η · δⱼ · xᵢ
w ← w + Δw
출력층 vs 은닉층 비교
항목 출력층 (Output Layer) 은닉층 (Hidden Layer)
오차 신호 명시적: eₖ = hₖ − yₖ 없음: Credit Assignment Problem
델타 오차 δₖ = eₖ · σ'(sₖ) δⱼ = σ'(sⱼ) · Σₖ wₖⱼδₖ
민감도 인자 ∂ℰ/∂wₖⱼ = δₖ · zⱼ ∂ℰ/∂wⱼᵢ = δⱼ · xᵢ
가중치 갱신 Δwₖⱼ = −η · δₖ · zⱼ Δwⱼᵢ = −η · δⱼ · xᵢ
계산 난이도 쉬움 (직접 계산 가능) 어려움 (역전파로 해결)
08

전체 역전파 알고리즘

Stochastic Back-Propagation Algorithm
1:initialize all weights {wⱼᵢ, wₖⱼ}
2:repeat
3:pick n ∈ {1, 2, ..., N} // 샘플 하나 랜덤 선택
4:forward: compute all zⱼ, hₖ, eₖ // 모든 활성화 & 오차 계산
5:backward: compute all δₖ, δⱼ // 모든 델타 오차 계산
6:update weights:
hidden(j)→output(k): wₖⱼ ← wₖⱼ − η · δₖ · zⱼ
input(i)→hidden(j): wⱼᵢ ← wⱼᵢ − η · δⱼ · xᵢ
7:until it is time to stop
8:return final weights {wⱼᵢ*, wₖⱼ*}

딥러닝의 동기 (Deep Learning: Motivation)

신경망: 강력한 모델

Universal Approximator
충분한 뉴런이 있다면 어떤 함수도 근사 가능

  • GMM: 충분한 가우시안 있으면 → universal density estimator
  • ANN: 충분한 뉴런 있으면 → universal function estimator
  • 더 많은 레이어 → 더 복잡한 의사결정 영역 → 더 "지능적"
레이어 수에 따른 의사결정 영역
구조의사결정 영역 유형
단층 (Single Layer)Half plane — 초평면으로 경계
2층 (Two Layer)볼록 열린/닫힌 영역 (Convex open/closed)
3층 (Three Layer)임의 복잡도 영역 (Arbitrary, 노드 수에 제한)
시각 피질(Visual Cortex)에서의 영감
  • 인간 뇌: 시각 처리에 최소 5~10개 레이어 사용
  • 인간 수준 지능을 위한 계층적(hierarchical) 모델 필요
  • V1(엣지, 코너) → V2 → V4 → AIT(얼굴, 물체) → PFC(의사결정) 순으로 처리

문제: 레이어가 많아질수록 학습이 훨씬 어려워짐 → 소실 기울기, 과적합, 실행 시간 문제

ANN 역사: 역전파 발견(1980s) → 소실 기울기 등으로 암흑기 → 비지도 사전학습 + 파인튜닝으로 재도약 (딥러닝)

10

소실 기울기 문제 (Vanishing Gradient Problem)

소실 기울기란?

역전파 시 오차 신호가 층을 거쳐 전파되면서 점점 작아지는 현상. 피드포워드 뿐만 아니라 순환 신경망(RNN)에서도 발생.

활성화 함수 비교
함수소실 기울기
Logistic 심각하게 겪음
Tanh Logistic보다 낫지만 여전히 존재
ReLU 기울기 소실 없음!

ReLU는 양수 영역에서 기울기가 항상 1 → 층이 깊어도 기울기가 사라지지 않음

기울기(Gradient) 비교
  • Logistic 기울기: 최대 0.25, s가 크거나 작으면 거의 0
  • Tanh 기울기: 최대 1.0 (Logistic보다 크지만 여전히 소실)
  • ReLU 기울기: 양수 영역에서 항상 1 → 소실 없음

역전파 시 층을 통과할 때마다 기울기가 σ'(s)배 곱해짐. σ'(s) < 1이면 반복 곱으로 지수적으로 감소!

요약 (Summary)

순전파 (Forward Propagation)
활성화 함수 (Sigmoid)
σ(s) = 1 / (1 + e⁻ˢ)
은닉층 출력
zⱼ(x) = σ( Σᵢ wⱼᵢ · xᵢ )
출력층 출력
hₖ(x) = σ( Σⱼ wₖⱼ · zⱼ )
역전파 (Back Propagation)
출력층 — 민감도 인자
∂ℰ/∂wₖⱼ = δₖ · zⱼ
은닉층 — 민감도 인자
∂ℰ/∂wⱼᵢ = δⱼ · xᵢ
출력층 — 델타 오차
δₖ = σ'(sₖ) · eₖ
eₖ = hₖ − yₖ
은닉층 — 델타 오차
δⱼ = σ'(sⱼ) · Σₖ wₖⱼδₖ
출력층 δ를 역방향으로 전파
출력층 — 가중치 갱신
Δwₖⱼ = −η · δₖ · zⱼ
은닉층 — 가중치 갱신
Δwⱼᵢ = −η · δⱼ · xᵢ
핵심 개념 총정리
개념내용
