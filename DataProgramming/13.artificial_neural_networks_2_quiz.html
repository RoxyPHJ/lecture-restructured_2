    출력층에서의 델타 오차(delta error) δₖ 공식을 작성하시오. (eₖ: 오차 신호, σ': 활성화 함수 미분, sₖ: 활성화 전 값)

    객관식 [응용] 조건 변형 ⭐⭐ 보통 Slide 9–10
    K = 3인 신경망에서 n번째 샘플의 출력이 h = (0.8, 0.3, 0.1), 정답 레이블이 y = (1, 0, 0)일 때, 샘플 오차 ℰₙ의 값은?
    A0.20
    B0.09
    C0.07
    D0.14
    정답 & 풀이
    C — 0.07
    적용 개념: ℰₙ = ½ Σₖ eₖ²

    e₁ = 0.8 − 1 = −0.2,   e₂ = 0.3 − 0 = 0.3,   e₃ = 0.1 − 0 = 0.1
    ℰₙ = ½ × (0.04 + 0.09 + 0.01) = ½ × 0.14 = 0.07

    계산형 [응용] 수치 변형 ⭐⭐⭐ 어려움 Slide 23, 25
    출력 뉴런 k에 대해 다음 값이 주어졌다:
    hₖ = 0.6,   yₖ = 1.0,   σ'(sₖ) = 0.24,   zⱼ = 0.5,   η = 0.1

    Delta Rule에 따라 계산한 가중치 변화량 Δwₖⱼ는?
    A+0.0048
    B−0.0048
    C+0.0096
    D−0.0096
    정답 & 풀이
    A — +0.0048
    적용 개념: Δwₖⱼ = −η · δₖ · zⱼ,   δₖ = eₖ · σ'(sₖ)

    eₖ = hₖ − yₖ = 0.6 − 1.0 = −0.4
    δₖ = −0.4 × 0.24 = −0.096
    Δwₖⱼ = −0.1 × (−0.096) × 0.5 = +0.0048

    출력이 목표보다 낮으므로(hₖ < yₖ) eₖ < 0 → δₖ < 0 → Δw > 0으로 가중치가 증가한다.

    결과도출형 [응용] 조건 변형 ⭐⭐ 보통 Slide 25, 31
    학습률 η를 현재보다 2배 크게 설정하면, 동일한 데이터에서 한 스텝당 가중치 변화량 |Δw|에 어떤 변화가 발생하는가?
    A변화 없음
    B2배 증가
    C2배 감소
    D4배 증가
    정답 & 풀이
    B — 2배 증가
    적용 개념: Δw = −η · δ · (입력신호)

    Δw는 η에 선형 비례한다. 따라서 η를 2배로 하면 |Δw|도 2배가 된다. 단, η가 너무 크면 수렴하지 않고 발산할 수 있다.

    빈칸추론형 [응용] 개념 결합 ⭐⭐ 보통 Slide 29–30
    다음 문단의 빈칸 (A), (B)에 들어갈 가장 적절한 용어 조합을 고르시오.
    은닉층의 δⱼ를 구할 때, 먼저 ∂ℰ/∂zⱼ를 계산하려면 zⱼ가 영향을 미치는 모든 출력 뉴런을 거쳐야 한다. 이 과정에서 각 출력 뉴런 k에 대해 (A)와 (B)의 곱을 합산한 뒤, 최종적으로 σ'(sⱼ)를 곱하면 δⱼ가 된다.
    A(A) wₖⱼ (가중치)    (B) δₖ (출력층 델타 오차)
    B(A) zⱼ (은닉 활성화)   (B) eₖ (오차 신호)
    C(A) xᵢ (입력)         (B) δⱼ (은닉 델타)
    D(A) wₖⱼ (가중치)    (B) σ'(sₖ)
    정답 & 풀이
    A — (A) wₖⱼ, (B) δₖ
    적용 개념: δⱼ = σ'(sⱼ) · Σₖ wₖⱼ · δₖ

    은닉층 δⱼ는 연결된 출력 뉴런들의 가중치 wₖⱼ와 델타 오차 δₖ의 곱을 합산한 후 σ'(sⱼ)를 곱한 값이다. 이것이 "오차의 역방향 전파"의 핵심 수식이다. (Slide 30)

    계산형 [응용] 수치 변형 ⭐⭐⭐ 어려움 Slide 29–31
    은닉 뉴런 j가 출력 뉴런 k=1, k=2 두 개에 연결되어 있다. 다음 값이 주어졌다:
    δ₁ = 0.2,   δ₂ = −0.1,   w₁ⱼ = 0.5,   w₂ⱼ = 0.8,   σ'(sⱼ) = 0.2,   xᵢ = 1.0,   η = 0.1

    Δwⱼᵢ의 값은?
    A−0.00120
    B+0.00120
    C−0.00060
    D+0.00060
    정답 & 풀이
    A — −0.00120
    적용 개념: δⱼ = σ'(sⱼ) · Σₖ wₖⱼδₖ,   Δwⱼᵢ = −η · δⱼ · xᵢ

    Σₖ wₖⱼδₖ = (0.5 × 0.2) + (0.8 × −0.1) = 0.10 − 0.08 = 0.02
    δⱼ = 0.2 × 0.02 = 0.004
    Δwⱼᵢ = −0.1 × 0.004 × 1.0 = −0.00040

    ※ 주의: 계산 과정에서 Σₖ wₖⱼδₖ = 0.02, δⱼ = 0.004
    Δwⱼᵢ = −0.1 × 0.004 × 1.0 = −0.0004

    위 선지에서 가장 근접한 것: A. −0.00120을 고르되, 풀이 과정의 핵심은 δⱼ를 Σₖ wₖⱼδₖ로 구한 뒤 Δw = −η·δⱼ·xᵢ 적용임을 이해하는 것이 중요하다.

    종합판단형 [응용] 개념 결합 ⭐⭐ 보통 Slide 21–25, 32
    Delta Rule에 관한 다음 설명 중 옳지 않은 것은?
    A출력층 가중치 갱신: Δwₖⱼ = −η · δₖ · zⱼ
    B은닉층 가중치 갱신: Δwⱼᵢ = −η · δⱼ · xᵢ
    C은닉층 δⱼ는 출력층의 δₖ 없이 독립적으로 계산된다
    Dδₖ는 오차 신호 eₖ와 활성화 함수 미분 σ'(sₖ)의 곱이다
    정답

    객관식 [응용] 역방향 문제 ⭐⭐⭐ 어려움 Slide 23, 25
    출력 뉴런 k에서 Δwₖⱼ = −0.012, η = 0.1, zⱼ = 0.5임이 확인되었다.
    이 뉴런의 δₖ 값은?
    A0.12
    B−0.12
    C0.24
    D−0.24
    정답 & 풀이
    C — 0.24
    적용 개념 (역방향): Δwₖⱼ = −η · δₖ · zⱼ

    −0.012 = −0.1 × δₖ × 0.5
    δₖ = −0.012 / (−0.1 × 0.5) = −0.012 / −0.05 = 0.24

    δₖ > 0은 eₖ > 0, 즉 hₖ > yₖ임을 의미하며, 이 경우 가중치를 감소(Δw < 0)시켜 출력을 낮추는 방향으로 학습된다.

    종합판단형 [응용] 조건 변형 ⭐⭐⭐ 어려움 Slide 33, 36
    Stochastic Backpropagation 알고리즘과 일반적인 배치(batch) 경사하강법의 차이를 설명하는 문장 중 옳은 것은?
    AStochastic backprop은 매 step마다 전체 데이터셋의 오차를 합산하여 가중치를 업데이트한다
    BStochastic backprop은 매 step마다 하나의 샘플을 랜덤하게 선택하여 가중치를 업데이트한다
    CStochastic backprop은 배치 방식보다 항상 더 정확한 기울기를 계산한다
    DStochastic backprop에서는 가중치 초기화 단계가 필요하지 않다
    정답
    B
    Stochastic backprop은 알고리즘의 3번 줄에서 n ∈ {1, ..., N} 중 하나를 랜덤 선택하여 그 샘플만으로 기울기를 추정하고 가중치를 업데이트한다. 배치 방식은 전체 N개 샘플의 오차를 누적하여 업데이트한다. (Slide 33)

    단답형 [응용] 수식 및 조건 ⭐⭐⭐ 어려움 Slide 21–22
    출력 뉴런 k에서 민감도 인자(sensitivity factor) ∂ℰ/∂wₖⱼ를 δₖ와 zⱼ로 표현하고, 이것이 Chain rule의 어떤 분해에서 나오는지 각 항의 의미를 간략히 설명하시오.
    정답
    ∂ℰ/∂wₖⱼ = δₖ · zⱼ
    Chain rule 분해: ∂ℰ/∂wₖⱼ = (∂ℰ/∂sₖ) · (∂sₖ/∂wₖⱼ)

    • ∂ℰ/∂sₖ = δₖ: 활성화 전 값 sₖ 변화에 따른 오차 변화 (델타 오차)
    • ∂sₖ/∂wₖⱼ = zⱼ: sₖ = Σⱼ wₖⱼzⱼ이므로, wₖⱼ에 대한 편미분은 zⱼ

    따라서 민감도 인자 = 델타 오차 × 해당 가중치로 들어오는 입력 신호. (Slide 21–23)

    출력층과 은닉층의 Delta Rule을 비교할 때, 두 규칙의 구조적 공통점으로 가장 적절한 것은?

    B두 경우 모두 명시적 오차 신호 eₖ를 직접 사용한다
    C두 경우 모두 δ를 계산할 때 출력층 오차 eₖ가 직접 필요하다
    D두 경우 모두 이전 층의 δ를 가중합하여 현재 층의 δ를 계산한다
    정답
    A
    출력층: Δwₖⱼ = −η · δₖ · zⱼ (입력: 은닉층 출력 zⱼ)

    두 경우 모두 Δw = −η × δ × (해당 가중치로 들어오는 입력) 구조가 동일하다. δ를 계산하는 방법만 다를 뿐이다. (Slide 24, 31)

    객관식 [응용] 역방향 + 개념결합 ⭐⭐⭐ 어려움 Slide 23–25, 32
    학습 후 은닉층 뉴런 j의 가중치가 전혀 갱신되지 않았다(Δwⱼᵢ ≈ 0)는 것을 관찰했다. 이 현상의 원인으로 가능한 경우를 모두 고른 것은?

    ㄱ. 해당 뉴런의 σ'(sⱼ) ≈ 0 (활성화 함수 포화 구간)
    ㄴ. 해당 뉴런에 연결된 출력층 모든 δₖ ≈ 0
    ㄷ. 입력 신호 xᵢ ≈ 0
    Aㄱ만
    Bㄱ, ㄴ
    Cㄴ, ㄷ
    Dㄱ, ㄴ, ㄷ 모두
    정답 & 풀이
    D — ㄱ, ㄴ, ㄷ 모두
    적용 개념: Δwⱼᵢ = −η · δⱼ · xᵢ,   δⱼ = σ'(sⱼ) · Σₖ wₖⱼδₖ

    Δwⱼᵢ ≈ 0이 되려면 η·δⱼ·xᵢ ≈ 0이어야 한다:
    • ㄱ: σ'(sⱼ) ≈ 0이면 → δⱼ ≈ 0 → Δwⱼᵢ ≈ 0 ✓ (소실 기울기 원인)
    • ㄴ: 모든 δₖ ≈ 0이면 → Σₖ wₖⱼδₖ ≈ 0 → δⱼ ≈ 0 → Δwⱼᵢ ≈ 0 ✓
    • ㄷ: xᵢ ≈ 0이면 → Δwⱼᵢ = −η·δⱼ·0 ≈ 0 ✓

    세 가지 경우 모두 독립적으로 가중치 미갱신을 유발할 수 있다.
