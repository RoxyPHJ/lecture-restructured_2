01 Introduction
생물학적 뉴런 (Biological Neuron)
  • 신경계의 특수화된 세포 — 전기·화학 신호로 정보를 처리·전달
  • 뇌의 기본 구성 단위
  • 신호가 충분히 강해지면 축삭(axon)을 따라 전달되고, 시냅스(synapse)를 통해 다음 뉴런으로 전달
뉴런 → 시냅스 → 다음 뉴런: 생물학적 신호 전달 경로가 ANN의 설계 근거가 됨
인공 신경망 (ANN) 개요
  • 뇌에서 영감을 받은 계산 모델 (computational model inspired by brain)
  • 기계학습(machine learning)과 패턴인식(pattern recognition) 가능
  • 1990년대 초까지 인기 → 후반 쇠퇴 → 딥러닝·AlphaGo·ChatGPT로 부활
전통 모델최신 변형
Feedforward Neural Network (MLP)RBM, AE, CNN, RNN, GAN …
MLP 핵심 아이디어
Step 1
입력의 선형 조합을 추출하여 파생 피처를 생성
Step 2
이 피처들의 비선형 함수로 타깃을 모델링
주의 — 명칭 오류: MLP(Multilayer Perceptron)는 사실 퍼셉트론의 다층 조합이 아니라, 로지스틱 모델(연속 비선형)의 다층 조합임. 퍼셉트론은 불연속 비선형.

03 활성화 함수 (Activation Function)
3종류 비교
이름수식특징
Linear σ(s) = s 선형 · 비선형성 없음
Sigmoid (logistic) σ(s) = 1/(1+e⁻ˢ) 연속 비선형 · 출력 [0,1]
Hard Threshold (sign) σ(s) = sign(s) 불연속 비선형 · 퍼셉트론
단순화 가정: 네트워크 내 모든 뉴런이 동일한 σ 함수를 사용 (보통 logistic sigmoid)
Logistic Sigmoid 상세
σ(s) = 1 / (1 + e⁻ˢ)
  • 출력 범위: (0, 1)
  • s = 4.6 → σ ≈ 0.99
  • s = -4.6 → σ ≈ 0.01
  • s = 0 → σ = 0.5 (중앙)
  • 부드러운 S자 곡선 — 미분 가능
σ'(s) = σ(s)·(1 − σ(s)) — 역전파 계산에 유리

05 Rectifier / ReLU / Leaky ReLU
Rectifier (ReLU)
σ(s) = max(0, s)

딥 신경망에서 매우 인기 있는 활성화 함수

  • 활성화·기울기의 역전파 허용 (non-zero values는 소수)
  • Vanishing gradient 문제 완화: 기울기가 상수(1)로 전파
  • 생물학적으로 더 그럴듯: sigmoid보다 더 현실적인 뉴런 발화 모델
  • Nair & Hinton (2010): 상대적 강도 정보를 여러 층을 거쳐 보존
Dying ReLU 문제: s ≤ 0인 구간에서 기울기=0 → 학습 도중 일부 뉴런이 영구적으로 "죽어" 업데이트 불가
Softplus (smooth approximation)
σ(s) = ln(1 + eˢ)
σ'(s) = eˢ/(1+eˢ) = 1/(1+e⁻ˢ) [logistic]
Leaky ReLU
σ(s) = s  if s > 0
σ(s) = αs  otherwise (α≈0.01)

Dying ReLU를 해결하기 위해 음의 구간에 작은 기울기 α 부여

Single-Layer vs Multilayer Feedforward Network

신호의 두 가지 유형
1. Function Signal (순전파)
입력에서 시작 → 네트워크를 순방향으로 전파 → 출력에서 산출
2. Error Signal (역전파)
출력 뉴런에서 발생 → 역방향으로 전파 → 가중치 업데이트에 사용
각 뉴런의 두 가지 계산
  1. 출력에 나타나는 함수 신호: 입력과 가중치의 연속 비선형 함수
  2. 역전파에 필요한 기울기 벡터 추정: ∇ε(w) (오차 표면의 가중치에 대한 기울기)

정의

08 은닉층의 역할 (Function of Hidden Neurons)
Feature Detector로서의 은닉 뉴런
  • 각 레이어는 "분산 표현(Distributed Representation)"에 해당
  • 은닉 뉴런은 특징 탐지기(Feature Detector) 역할
  • 학습이 진행되면서 훈련 데이터의 중요한 특징을 점진적으로 발견
  • 입력 데이터를 비선형 변환하여 피처 공간(Feature Space)으로 매핑
예: 64-2-3 네트워크 — 3가지 문자 분류
입력 64차원 → 은닉 2유닛 → 출력 3유닛
학습된 입력→은닉 가중치가 분류에 유용한 특징 그루핑을 기술
레이어 깊이와 특징 계층
레이어추출하는 특징예 (이미지)
Low-Level엣지, 색상, 텍스처선분, 코너
Mid-Level부분 패턴바퀴, 눈
High-Level의미론적 개념자동차, 얼굴
Output클래스 분류cat / dog / horse
은닉층 수 ↑ → 표현력 ↑, 지능 ↑   BUT   학습 난이도 ↑ (gradient vanishing, overfitting 등)
