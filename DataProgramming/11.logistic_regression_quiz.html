로지스틱 함수 θ(s)의 올바른 수식은?
① θ(s) = s / (1 + s)
② θ(s) = eˢ / (1 + eˢ) = 1 / (1 + e⁻ˢ)
③ θ(s) = (eˢ - e⁻ˢ) / (eˢ + e⁻ˢ)
④ θ(s) = max(0, s)
정답: ②
θ(s) = eˢ / (1+eˢ) = 1 / (1+e⁻ˢ)
③은 tanh(s) 수식이다. ④는 ReLU이다. θ는 입력 전체 실수에 대해 항상 0과 1 사이의 값을 출력한다.

OX 문제 ⭐ 📄 slide 11
로지스틱 함수 θ는 대칭성 1 - θ(s) = θ(-s)를 만족한다.
정답: O
1 - θ(s) = 1 - 1/(1+e⁻ˢ) = e⁻ˢ/(1+e⁻ˢ) = 1/(1+eˢ) = θ(-s)
이 대칭성 덕분에 P(y|x) = θ(y·wᵀx)로 통합 표현이 가능해진다. 이는 교차 엔트로피 오류를 간단하게 유도하는 핵심이다.

② 선형 회귀는 ∇E_in = 0을 설정하면 해석적 해(pseudo-inverse)가 존재한다

④ 로지스틱 회귀는 경사 하강법과 같은 반복적 최적화를 사용한다

Q6
단답형 ⭐ 📄 slide 36–38
경사 하강법에서 현재 위치의 가중치 w(t)에서 E_in을 가장 크게 감소시키는 이동 방향 v̂은 무엇인가? 수식으로 답하시오.
정답
v̂ = -∇E_in(w(t)) / ‖∇E_in(w(t))‖
테일러 1차 전개에 의해 ΔE_in ≈ η·∇E_in(w)ᵀ·v̂ ≥ -η‖∇E_in(w)‖. 등호는 v̂가 그래디언트의 반대 방향일 때 성립. → 음의 그래디언트 방향이 가장 가파른 하강 방향.

OX 문제 ⭐⭐ 📄 slide 39
교차 엔트로피 오류 E_in(w)은 w에 대한 볼록 함수(convex function)이므로, 경사 하강법은 시작 위치에 관계없이 항상 지역 최솟값에 갇히지 않고 전역 최솟값으로 수렴한다.
정답: O
E_in(w)의 Hessian이 Positive Semidefinite임을 확인하면 볼록성이 보장된다. 볼록 함수에는 유일한 전역 최솟값만 존재하므로 어디서 시작해도 같은 최솟값에 수렴한다. 이는 교차 엔트로피를 사용하는 핵심 이유 중 하나다.

로지스틱 회귀 알고리즘의 그래디언트 수식을 쓰시오. (N개 샘플 기준)

Q10
서술형 ⭐⭐ 📄 slide 47–49
경사 하강법에서 학습률(η)이 너무 작을 때와 너무 클 때 각각 어떤 문제가 발생하는지 설명하고, 이를 해결하기 위한 가변 학습률 전략을 서술하시오.
채점 기준 (키워드 & 논리 구조)
필수 키워드

① 수렴 속도 느림 / ② 발산·진동 / ③ 그래디언트 norm 크기 / ④ 가변 학습률 η_t = η‖∇E_in(w(t))‖ / ⑤ 정규화 항 상쇄

모범 답안:
η가 너무 작으면 최솟값에서 멀리 있을 때 보폭이 너무 작아 수렴이 매우 느리다. 반대로 η가 너무 크면 최솟값 근처에서 보폭이 커서 E_in이 진동하거나 발산할 수 있다.

이상적 전략은 멀 때 크게, 가까울 때 작게 움직이는 것이다. 그래디언트 norm ‖∇E_in‖은 최솟값에서 멀수록 크고 가까울수록 작으므로, η_t = η·‖∇E_in(w(t))‖로 설정하면 이 성질을 자동으로 활용할 수 있다. 이때 v̂의 정규화 항과 학습률이 상쇄되어 최종 업데이트 식은 w(t+1) = w(t) - η·∇E_in(w(t))로 간단해진다.

신호 s = 2일 때 로지스틱 함수 θ(2)의 근사값은? (e ≈ 2.718 사용)

② 약 0.73
③ 약 0.88
④ 약 0.95

결과 도출형 [응용] ⭐⭐ 📄 slide 21
훈련 샘플 (xₙ, yₙ = +1)이 있을 때, wᵀxₙ을 더 크게(양수 방향으로) 만들면 교차 엔트로피 손실 ln(1 + e^{-yₙwᵀxₙ})은 어떻게 변하는가?
① 증가한다
② 감소한다
③ 변하지 않는다
④ 증가했다가 다시 감소한다

yₙ=+1이므로 손실 = ln(1 + e^{-wᵀxₙ})
wᵀxₙ → ∞이면 e^{-wᵀxₙ} → 0, 손실 → ln(1) = 0

yₙ=+1이면 wᵀxₙ≫0을 장려한다. 즉, 모델이 올바른 방향의 신호를 강하게 줄수록 오류가 줄어든다. yₙ=-1인 경우는 반대로 wᵀxₙ≪0을 장려한다.
Q13
객관식 [응용] ⭐⭐ 📄 slide 17, 22
로지스틱 회귀에서 P(y|x)를 θ(y·wᵀx)로 통합 표현할 수 있는 핵심 이유는?
① wᵀx가 음수일 때 자동으로 0이 되기 때문이다
② 1-θ(s) = θ(-s)라는 대칭성이 성립하여, y=-1인 경우의 1-h(x)를 θ(-wᵀx)로 변환할 수 있기 때문이다
③ θ(s)의 범위가 [0,1]이어서 확률의 합이 1이 되기 때문이다
④ y∈{-1,+1}이면 y² = 1이므로 부호가 상쇄되기 때문이다
정답: ②
풀이 과정

y=+1: P(y|x) = h(x) = θ(wᵀx) = θ(+1·wᵀx)
y=-1: P(y|x) = 1-h(x) = 1-θ(wᵀx) = θ(-wᵀx) = θ(-1·wᵀx)
두 경우 모두 θ(y·wᵀx)로 통합

이 통합 덕분에 NLL 유도 시 y=+1과 y=-1 케이스를 하나의 식으로 처리할 수 있어 교차 엔트로피 오류 공식이 깔끔하게 도출된다.

계산형 [응용] ⭐⭐⭐ 📄 slide 25–26
N=3인 데이터셋에서 각 샘플의 yₙwᵀxₙ 값이 {2, -1, 0}일 때, E_in(w)는? (ln 2 ≈ 0.693, e ≈ 2.718)
① 약 0.56
② 약 0.70
③ 약 0.84
④ 약 0.92
정답: ②
풀이 과정

E_in(w) = (1/N) Σ ln(1 + e^{-yₙwᵀxₙ})

n=1: yₙwᵀxₙ=2 → ln(1+e⁻²) = ln(1+0.135) ≈ ln(1.135) ≈ 0.127
n=2: yₙwᵀxₙ=-1 → ln(1+e¹) = ln(1+2.718) ≈ ln(3.718) ≈ 1.312
n=3: yₙwᵀxₙ=0 → ln(1+e⁰) = ln(2) ≈ 0.693

E_in = (0.127 + 1.312 + 0.693) / 3 = 2.132 / 3 ≈ 0.711

n=2(yₙwᵀxₙ=-1)가 가장 큰 손실을 발생시키는 것에 주목. 이 샘플은 예측 부호가 틀린 경우로, 경사 하강법이 이 샘플의 가중치를 가장 많이 조정하려 한다.
Q16
빈칸 추론형 [응용] ⭐⭐⭐ 📄 slide 28–31
크로스 엔트로피 공식 p·log(1/q) + (1-p)·log(1/(1-q))에서 로지스틱 회귀의 맥락에 맞게 p와 q를 올바르게 대응시킨 것은?
(단, xₙ은 n번째 입력, yₙ은 레이블, h(xₙ)은 모델 출력)
① p = h(xₙ), q = [yₙ=+1]
② p = [yₙ=+1], q = h(xₙ)
③ p = θ(wᵀxₙ), q = yₙ
④ p = yₙ, q = wᵀxₙ
정답: ②
풀이 과정

크로스 엔트로피는 관측 PMF {p, 1-p}를 피팅 PMF {q, 1-q}로 근사할 때의 오류.
관측 PMF: {[yₙ=+1], 1-[yₙ=+1]} → p = [yₙ=+1]
피팅 PMF: {h(xₙ), 1-h(xₙ)} → q = h(xₙ)
대입 시 NLL의 각 항 [yₙ=+1]·log(1/h(xₙ)) + [yₙ=-1]·log(1/(1-h(xₙ)))와 일치

p는 실제 관측된 분포(0 또는 1), q는 모델이 예측한 분포(확률값). 교차 엔트로피는 관측과 예측 간의 "거리"를 측정한다.
Q17
코드 완성형 [응용] ⭐⭐ 📄 slide 52
아래 Python 코드에서 빈칸을 채워 로지스틱 회귀의 그래디언트 업데이트를 완성하시오.
import numpy as np def sigmoid(s): return 1.0 / (1.0 + np.exp(-s)) def compute_gradient(X, y, w): # X: (N, d+1), y: (N,), w: (d+1,) N = X.shape[0] scores = X @ w # wᵀxₙ for each n ______(A)______ # θ(-yₙwᵀxₙ) grad = -(1.0 / N) * X.T @ __(B)__ return grad def logistic_regression(X, y, eta=0.1, T=1000): w = np.zeros(X.shape[1]) for _ in range(T): grad = compute_gradient(X, y, w) ______(C)______ # 가중치 업데이트 return w
정답
(A): theta = sigmoid(-y * scores) (B): (y * theta) 또는 (y[:, None] * theta[:, None]).squeeze() → 정확히는: (y * theta) shape (N,), X.T @ (y*theta) shape (d+1,) (C): w = w - eta * grad
개념 연결

∇E_in = -(1/N)·Xᵀ·(y ⊙ θ(-y·wᵀx))
(A): θ(-yₙwᵀxₙ) 계산 → sigmoid(-y * scores)
(B): y ⊙ theta로 원소별 곱
(C): 경사 하강법 업데이트 w ← w - η·∇E_in

Q18
결과 도출형 [응용] ⭐⭐⭐ 📄 slide 47–49
가변 학습률 η_t = η·‖∇E_in(w(t))‖을 도입했을 때, 업데이트 식 w(t+1) = w(t) + η_t·v̂_t를 단순화하면 어떻게 되는가? (v̂_t는 단위 벡터)
① w(t+1) = w(t) + η·v̂_t
② w(t+1) = w(t) - η·∇E_in(w(t))
③ w(t+1) = w(t) - η·‖∇E_in(w(t))‖
④ w(t+1) = w(t) + η·∇E_in(w(t))
정답: ②
풀이 과정

v̂_t = -∇E_in(w(t)) / ‖∇E_in(w(t))‖ (단위 벡터 정의)
η_t = η · ‖∇E_in(w(t))‖ (가변 학습률)

w(t+1) = w(t) + η_t · v̂_t
= w(t) + η·‖∇E_in‖ · (-∇E_in / ‖∇E_in‖)
= w(t) - η·∇E_in(w(t)) ← ‖·‖ 상쇄

이것이 표준 경사 하강법 업데이트 공식이다. 가변 학습률의 도입이 단위벡터의 정규화 항을 자동으로 상쇄시켜, 구현은 단순하지만 멀 때 크게/가까울 때 작게 움직이는 효과를 얻는다.

서술형 [응용] ⭐⭐⭐ 📄 slide 22–27
로지스틱 회귀에서 교차 엔트로피 오류 E_in(w)를 최소화하는 것이 왜 최대 우도 추정(MLE)과 동치인지 수식적 흐름을 포함하여 설명하시오.
채점 기준 (키워드 & 논리 구조)
필수 키워드 (5개)

① P(y|x) = θ(y·wᵀx) / ② 독립 가정 · 곱(product) / ③ 로그 취하기(단조 증가) / ④ 부호 반전 → 최소화 / ⑤ E_in(w) = (1/N)Σln(1+e^{-ywᵀx})

모범 답안:
데이터가 독립적으로 생성되었다 가정하면 전체 우도는 Π P(yₙ|xₙ). P(y|x) = θ(y·wᵀx)를 대입하면 Likelihood = Π θ(yₙwᵀxₙ)이다.

이를 최대화하는 것은 단조 증가 함수 log를 취해 log-likelihood를 최대화하는 것과 동치다. (1/N)Σln P = (1/N)Σln θ(yₙwᵀxₙ). 다시 부호를 바꾸면 최솟값 문제가 되어 NLL = (1/N)Σ ln(1/θ(yₙwᵀxₙ)) = (1/N)Σ ln(1+e^{-yₙwᵀxₙ})가 E_in이다. 결국 MLE 최대화 = NLL 최소화 = E_in 최소화.

객관식 [응용] ⭐⭐ 📄 slide 14–15
tanh(s)와 로지스틱 함수 θ(s)의 관계로 옳은 것은?
① tanh(s) = θ(s) - 0.5
② tanh(s) = 2·θ(2s) - 1
③ tanh(s) = θ(s) / (1 - θ(s))
④ tanh(s) = 1 - θ(s)
정답: ②
풀이 과정

θ(2s) = 1/(1+e^{-2s})
2·θ(2s) - 1 = 2/(1+e^{-2s}) - 1 = (2 - 1 - e^{-2s})/(1+e^{-2s})
= (1 - e^{-2s})/(1+e^{-2s})
분자분모에 e^s 곱: = (e^s - e^{-s})/(e^s + e^{-s}) = tanh(s) ✓

즉 tanh는 θ를 선형 변환한 것이다. tanh의 범위는 (-1, 1)이고 θ의 범위는 (0, 1)이다. 두 함수 모두 시그모이드 계열이며 신경망에서 활성함수로 사용된다.

서술형 [응용] ⭐⭐⭐ 📄 slide 34–57
선형 회귀는 해석적 해(pseudo-inverse)를 갖지만, 로지스틱 회귀는 반복 최적화가 필요하다. 두 모델의 최적화 방식이 다른 근본적인 이유를 ∇E_in 수식을 활용하여 비교 설명하시오.
채점 기준 (키워드 & 논리 구조)
필수 키워드 (5개)

① 선형 회귀 ∇E_in = (2/N)Xᵀ(Xw-y) = 0 → Xᵀy = Xᵀ(Xw) → w = X⁺y / ② 로지스틱 ∇E_in = -(1/N)Σyₙxₙθ(-yₙwᵀxₙ) / ③ 비선형(θ) → 닫힌 해 불가 / ④ 반복 최적화(경사 하강법) / ⑤ 볼록성 → 전역 최솟값 보장

모범 답안:
선형 회귀의 ∇E_in = (2/N)Xᵀ(Xw-y)는 w에 대해 선형이므로 ∇E_in=0으로 설정하면 Xᵀ(Xw)=Xᵀy, 즉 w = (XᵀX)⁻¹Xᵀy = X⁺y라는 닫힌 해를 얻는다.

반면 로지스틱 회귀의 ∇E_in = -(1/N)Σyₙxₙ·θ(-yₙwᵀxₙ)는 비선형 함수 θ가 w를 포함하므로, ∇E_in=0을 w에 대해 해석적으로 풀 수 없다. 따라서 반복적으로 그래디언트를 계산하며 업데이트하는 경사 하강법이 필요하다. 다만 교차 엔트로피 E_in이 볼록이므로 항상 전역 최솟값으로 수렴함이 보장된다.
