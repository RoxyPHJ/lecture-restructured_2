01

왜 통계적 검증이 필요한가?

동기
"모델 A의 F1 = 0.823, 모델 B의 F1 = 0.815 → 모델 A가 진짜 더 좋은 건가?"

교차 검증 점수에는 랜덤성이 포함됩니다 (데이터 분할 방식, 가중치 초기화 등). 0.8% 차이가 의미 있는 차이인가, 아니면 운의 차이인가?

같은 실험을 반복하면 모델 B가 더 좋게 나올 수도 있습니다.

🎲 주사위 비유

주사위를 6번 굴려 평균 눈이 4가 나옴 → 이 주사위는 편향되어 있는가?

공정한 주사위도 6번 시행만으로 충분히 평균 4가 나올 수 있음

→ 더 많은 시행과 통계적 검증이 필요!

ML 모델도 마찬가지 — 몇 번의 CV 점수로 '진짜 차이'를 확신할 수 없습니다.

해결책: 통계적 가설 검정
→ '우연일 가능성'을 수치로 정량화
6번 시행 — 눈 4가 많이 나왔다고 편향된 주사위가 아님!
02

정규 분포와 확률 분포

기초 이론
정규 분포 3가지 핵심 규칙
68% 규칙: μ ± 1σ 구간 안에 68% 확률
약 2/3의 데이터가 평균 ±1 표준편차 안에
95% 규칙: μ ± 2σ 구간 안에 95% 확률
가설 검정의 핵심 기준 (유의수준 α = 0.05)
99.7% 규칙: μ ± 3σ 구간 안에 99.7% 확률
3σ 밖은 매우 희귀한 사건 (0.3%)
Z = 2.0 이면 → 평균보다 2 표준편차 위 → 상위 약 2.5%
검정 통계량을 표준화하여 기각역과 비교!
정규 분포의 68-95-99.7 규칙
03

표본 분포와 중심 극한 정리 (CLT)

핵심 이론
Central Limit Theorem
모집단 분포와 무관하게, 표본 크기 n이 충분히 크면
표본 평균의 분포는 정규 분포에 수렴한다
X̄ ~ N(μ, σ²/n)  →  SE = σ/√n

n이 클수록 표본 평균의 분포가 좁아짐 (더 정확한 추정). 일반적으로 n ≥ 30이면 CLT가 잘 작동합니다.

🪙 동전 던지기 예시

10번 던지기 → 앞면 평균: 0.3~0.7 사이를 넓게 분포 (불안정)

1000번 던지기 → 앞면 평균: 0.48~0.52 사이에 집중 (안정적)

n이 클수록 표본 평균이 진짜 모평균(0.5)에 수렴!
→ CLT가 통계적 가설 검정을 가능하게 하는 이론적 토대
n이 클수록 표본평균 분포가 좁아짐 (SE = σ/√n)
04

가설 검정의 기본 틀

방법론
H₀ — 귀무가설 (Null Hypothesis)

'차이 없음', '효과 없음' — 기본 입장

예: 모델 A와 B의 성능은 같다

증거가 충분해야만 기각할 수 있음
H₁ — 대립가설 (Alternative Hypothesis)

'차이 있다', '효과 있다' — 우리가 주장하고 싶은 것

예: 모델 A의 성능이 모델 B보다 높다

충분한 증거가 있을 때 채택
검정 절차 (4단계)
①H₀ · H₁ 설정
→
②유의수준 α 설정
(보통 0.05)
→
③검정 통계량 계산
& p-value 산출
→
④p < α 이면
H₀ 기각 → H₁ 채택
05

p-value 이해와 오해

핵심 개념
p-value 정의
"귀무가설(H₀)이 사실이라는 가정 하에, 현재 관측된 결과만큼 극단적이거나 더 극단적인 결과가 나올 확률"
예시로 이해하기

H₀: 두 모델의 성능은 같다 (차이 = 0)
실험: 10-Fold CV에서 모델 A가 평균 0.05점 높음

p-value = 0.03 → H₀이 맞다면 이런 차이가 나올 확률 3%
α = 0.05로 설정 → p(0.03) < α(0.05) → H₀ 기각 → 유의미한 차이 있음!
p < 0.05

H₀ 기각 → 통계적으로 유의미한 차이 있음

p ≥ 0.05

H₀ 기각 실패 → '차이 없다'가 아닌 '증거 불충분'

⚠ p-value의 흔한 오해 3가지
오해올바른 해석
p < 0.05 이면 H₁이 95% 확률로 맞다?아님! p-value는 H₀ 가정 하 극단성만 나타냄 (사전 확률 고려 ✗)
p-value가 작을수록 효과(차이)가 크다?아님! '통계적 유의성' 측정. N이 크면 작은 차이도 p < 0.001 가능
p ≥ 0.05 이면 두 모델은 같다?아님! 단순히 '증거 불충분'. 표본이 작아도 p ≥ 0.05 가능
p-value는 강력한 도구지만 맹신 금물 — Effect Size와 함께 해석해야 함
06

t-검정 (독립 / 대응)

검정 방법
독립 표본 t-검정 (Independent t-test)

두 독립 그룹의 평균 차이가 통계적으로 유의한지 검정. 주로 소표본에서 사용.

t = (X̄₁ − X̄₂) / √(s₁²/n₁ + s₂²/n₂)  ,  df = n₁ + n₂ − 2
t 값이 클수록 두 그룹의 평균 차이가 큼
→ p-value 작아짐
df > 30 이면
t-분포 ≈ 정규 분포
⚠ ML에서 같은 데이터로 두 모델 비교 시 독립 t-검정은 부적절! → Paired t-test 사용
대응 표본 t-검정 (Paired t-test) — ML 모델 비교에 가장 적합

동일한 K-Fold 분할에서 두 모델을 각각 평가하여 각 Fold에서의 차이값을 분석

dᵢ = score_A(i) − score_B(i)  →  t = d̄ / (s_d / √n)
독립 t-test: 데이터 분할의 랜덤 변동이 분석을 방해 (외부 노이즈 포함)
Paired t-test: 같은 Fold에서 비교 → 데이터 분할 효과 제거
→ 훨씬 강력하고 정확한 검정 가능

구현: scipy.stats.ttest_rel(scores_a, scores_b)

07

다중 비교 문제 (Multiple Comparison Problem)

주의사항
⚠ 문제 상황

5개 모델을 쌍으로 비교 시 C(5,2) = 10번 검정 수행

각 검정에서 α = 0.05
10번 독립 검정 시
최소 1번 이상 오류 확률 = 1 − (0.95)¹⁰ ≈ 40%

→ 많이 검정할수록 우연히 유의하게 나올 확률 폭증!
Bonferroni 보정
α' = α / k  (k = 검정 횟수)

예: 10번 검정, α = 0.05 → α' = 0.005

단점: 매우 보수적 → 검정력(power) 감소
대안: Benjamini-Hochberg (FDR 제어, 탐색적 분석에 적합)
검정 횟수가 늘수록 FWER 폭증 → Bonferroni 보정 필요
08

비모수 검정 (Non-parametric Test)

대안 방법

t-검정의 가정: 데이터가 정규 분포를 따른다 → 이 가정이 위배될 때 비모수 검정 사용

Wilcoxon Signed-Rank Test

대응 표본 t-검정의 비모수 버전. 차이값(dᵢ)의 순위(rank)를 기반으로 검정

W = Σ rank(|dᵢ|) × sign(dᵢ)
언제 t-검정 vs 비모수 검정?
방법사용 조건장점
Paired t-test 데이터가 대략 정규 분포 & n ≥ 30 검정력(power)이 더 높음
Wilcoxon 정규성 가정 위배 or 이상치 있음 or n < 30 분포 가정 없이 안전
09

효과 크기 (Effect Size)

실질적 유의성
통계적 유의성(p < 0.05) ≠ 실질적 유의성
표본이 매우 크면 아주 작은 차이도 p < 0.001이 될 수 있음 — 차이의 '크기'를 별도로 측정해야 함
Cohen's d — 차이의 크기를 표준화
d = (X̄₁ − X̄₂) / s_pooled
d 값해석의미
d ≈ 0.2Small두 그룹이 약간 다름, 실용적 중요성 낮음
d ≈ 0.5Medium눈에 띄는 차이, 실용적으로 고려할 만함
d ≈ 0.8Large뚜렷하고 실용적으로 의미 있는 차이
실전 팁: p-value(유의성)와 Cohen's d(크기) 두 가지를 함께 보고하자
d가 클수록 두 분포의 겹침이 줄어듦

Python 실습

코드
모델 A vs B 통계적 검정 (슬라이드 11)
from sklearn.model_selection import cross_val_score, StratifiedKFold
from scipy import stats
from sklearn.svm import SVC
import numpy as np

cv = StratifiedKFold(n_splits=10, shuffle=True, random_state=42)
X = np.random.random((1000, 10)); X[:500] = X[:500] + 0.2
y_true = np.zeros(1000); y_true[:500] = 1

model_a = SVC(kernel='rbf', C=1.0, gamma='scale', probability=True)
model_b = SVC(kernel='rbf', C=100, gamma='scale', probability=True)
model_a.fit(X, y_true); model_b.fit(X, y_true)

scores_a = cross_val_score(model_a, X, y_true, cv=cv, scoring='f1')
scores_b = cross_val_score(model_b, X, y_true, cv=cv, scoring='f1')

# Paired t-test
t_stat, p_val = stats.ttest_rel(scores_a, scores_b)
print(f'Model A: {scores_a.mean():.3f} ± {scores_a.std():.3f}')
print(f'Model B: {scores_b.mean():.3f} ± {scores_b.std():.3f}')
print(f't={t_stat:.3f}, p={p_val:.4f}')
print('유의미한 차이 있음' if p_val < 0.05 else '통계적으로 유의미한 차이 없음')
ttest_rel: 대응(paired) 표본 t-검정 — 같은 CV Fold 점수 비교에 사용
단측 검정: ttest_rel(..., alternative='greater') 또는 'less' 옵션 추가 가능
종합 가설 검정 코드 (슬라이드 15)
from scipy import stats
import numpy as np

# 1. Paired t-test
t_stat, p_val = stats.ttest_rel(scores_a, scores_b)

# 2. Wilcoxon (비모수 — 정규성 불확실 시)
w_stat, p_wilcox = stats.wilcoxon(scores_a, scores_b)

# 3. 정규성 검정 (shapiro: p < 0.05 이면 비정규)
_, p_norm = stats.shapiro(scores_a - scores_b)

# 4. Cohen's d (효과 크기)
diff = scores_a - scores_b
d = diff.mean() / diff.std(ddof=1)

print(f"Paired t-test: t={t_stat:.3f}, p={p_val:.4f}")
print(f"Wilcoxon: p={p_wilcox:.4f}")
print(f"Cohen's d = {d:.3f}")
Shapiro-Wilk 검정: p < 0.05 이면 정규성 위배 → Wilcoxon 권장
Bonferroni 보정: p_val_adj = p_val × k (k = 총 검정 횟수)

좋은 ML 실험 설계란?

체크리스트
재현 가능한 실험을 위한 체크리스트
  • Random Seed 고정: random_state=42 — 코드 재실행 시 동일한 결과 보장
  • 동일한 CV 분할 사용: 두 모델을 정확히 같은 Fold에서 비교 (fair comparison)
  • 적절한 검정 선택: Paired t-test 또는 Wilcoxon — 독립 t-test 오용 금지
  • 다중 비교 보정: 여러 모델 비교 시 Bonferroni 등 보정 적용
  • Effect Size 보고: p-value와 함께 Cohen's d도 항상 제시
  • 실험 조건 명시: 데이터 버전, 전처리, 하이퍼파라미터 등 기록 (재현성)

핵심 요약

정리
📊

p-value

H₀이 맞을 때 관측 결과의 극단성. 유의성의 척도이지 차이 크기가 아님

📐

Paired t-test

ML 모델 비교의 표준. 동일 Fold에서 비교 → 분할 노이즈 제거

🔢

Cohen's d

효과 크기 측정. 0.2=Small, 0.5=Medium, 0.8=Large

🛡️

Bonferroni 보정

다중 검정 시 α' = α/k 적용. FWER 40% 폭증 방지

🧮

Wilcoxon

정규성 위배 or n<30 or 이상치 존재 시 Paired t-test 대신 사용

⚗️

CLT

n≥30이면 모집단 분포 무관하게 표본평균이 정규 분포에 수렴

핵심 메시지: 데이터만 있다고 좋은 ML이 아님 — 평가와 검증이 모델의 진짜 가치를 판별.
통계적 검증은 연구·프로젝트 결과를 설득력 있게 보고하는 핵심 도구입니다.
