Q1 기본 객관식 ⭐ 쉬움 슬라이드 4
1969년 Minsky & Papert의 《Perceptrons》가 AI 연구에 미친 직접적 영향으로 가장 적절한 것은?
AGPU 기반 병렬연산 연구가 촉진되었다
B단층 퍼셉트론의 XOR 문제 한계가 증명되어 연구 지원금이 대폭 삭감되었다
C역전파 알고리즘이 즉시 개발되어 다층 신경망 연구가 활성화되었다

활성화 함수 없이 선형층을 아무리 깊게 쌓아도, 수학적으로 단층 선형 모델과 동일하다.
⭕ O
❌ X
ANSWER

x=1, W¹=0.5, b¹=0, W²=2, b²=0, y=0 활성화 함수: ReLU, 손실 함수: MSE = (ŷ - y)²

BL = 0.5

BBinary Cross-Entropy에서 ŷ은 Sigmoid 함수의 출력으로 P(y=1|x)를 나타낸다
CCategorical Cross-Entropy는 다중 분류에 사용하며 레이블은 one-hot 형태를 취한다
DBinary Cross-Entropy는 다중 클래스 분류의 표준 손실 함수로 Softmax와 함께 사용된다

Q10 기본 서술형 ⭐⭐⭐ 어려움 슬라이드 21
역전파(Backpropagation)의 정의와 수학적 원리를 설명하고, 미니배치 경사하강법이 딥러닝의 표준 최적화 방식으로 채택된 이유를 배치 GD·SGD와 비교하여 서술하시오.
채점 기준
Chain Rule (연쇄 법칙) 출력층→입력층 방향 그래디언트 재사용 배치/SGD 트레이드오프 미니배치 절충안

▸ 감점 요인: Chain Rule 언급 없이 "오차를 거꾸로 전파"만 서술 시 감점. 미니배치 크기(B=32~256) 미언급. 배치·SGD의 구체적 장단점 없이 "중간" 수준으로만 서술 시 감점.

모범 답안

역전파는 연쇄 법칙(Chain Rule)을 출력층에서 입력층 방향으로 반복 적용하여 각 파라미터의 그래디언트를 계산하는 알고리즘이다. ∂L/∂θ = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂θ 와 같이 합성 함수의 미분을 분해하여 계산하며, 각 층은 상위 층에서 이미 계산된 ∂L/∂(앞 출력)을 재사용하므로 연산이 효율적이다.

배치 GD는 전체 N개 데이터를 매 스텝 사용하여 안정적이지만 속도가 느리고 대규모 데이터에 비효율적이다. SGD는 1개 샘플로 빠르게 업데이트하나 노이즈가 커 불안정하다. 미니배치 GD(B=32~256)는 두 방식의 장점을 결합하여 GPU 병렬처리 효율과 업데이트 안정성을 동시에 확보하므로 딥러닝의 표준 방식으로 채택된다.

Q11 [응용] 계산형 ⭐⭐ 보통 슬라이드 22
강의 예시와 동일한 구조의 2계층 MLP에서 아래 조건으로 순전파를 수행할 때, 손실값 L은?
x=2, W¹=0.3, b¹=0, W²=1.5, b²=0, y=1 활성화 함수: ReLU, 손실 함수: MSE = (ŷ - y)²
AL = 0.01
BL = 0.09
CL = 0.19
DL = 0.81
ANSWER & SOLUTION

B — L = 0.09

z¹ = 0.3×2 + 0 = 0.6 a¹ = ReLU(0.6) = 0.6 z² = 1.5×0.6 + 0 = 0.9 ŷ = 0.9 L = (0.9 - 1)² = (-0.1)² = 0.01...

잠깐 — 정답을 다시 계산: (0.9 - 1)² = 0.01. 선지 A가 정답.

z¹ = 0.3×2 = 0.6 → a¹ = 0.6 z² = 1.5×0.6 = 0.9 → ŷ = 0.9 L = (0.9 - 1)² = 0.01

정답: A — L = 0.01

변형 포인트

원본: x=1, W¹=0.5, W²=2, y=0 → L=1.0. 이 문제는 x·W¹·W²를 변경하고 정답 레이블을 y=0→y=1로 바꾸어 손실이 작아지도록 설계. 풀이 구조(z→ReLU→z²→MSE)는 동일.

Q12 [응용] 계산형 · 역방향 ⭐⭐⭐ 어려움 슬라이드 22
강의 2계층 MLP 역전파 예시에서 조건을 변형하였다. 아래 조건으로 ∂L/∂W²를 계산하면?
x=1, W¹=1.0, b¹=0, W²=0.5, b²=0, y=0 활성화 함수: ReLU, 손실 함수: MSE = (ŷ - y)² (단, ∂L/∂ŷ = 2(ŷ-y))
A∂L/∂W² = 0.5
B∂L/∂W² = 1.0
C∂L/∂W² = 1.5
D∂L/∂W² = 2.0
ANSWER & SOLUTION

A — ∂L/∂W² = 0.5

순전파: z¹ = 1.0×1 + 0 = 1.0 a¹ = ReLU(1.0) = 1.0 z² = 0.5×1.0 + 0 = 0.5 ŷ = 0.5 역전파: ∂L/∂ŷ = 2(ŷ-y) = 2(0.5-0) = 1.0 ∂ŷ/∂z² = 1 (항등 활성화) ∂L/∂W² = (∂L/∂ŷ)·(∂ŷ/∂z²)·a¹ = 1.0 × 1 × 1.0 = 0.5...
정정: ∂L/∂W² = ∂L/∂ŷ · a¹ = 1.0 × 1.0 = 1.0

정답: B — ∂L/∂W² = 1.0

∂L/∂ŷ = 2(0.5−0) = 1.0 ∂L/∂W² = 1.0 × 1 × a¹ = 1.0 × 1.0 = 1.0
변형 포인트

원본: W¹=0.5→1.0, W²=2→0.5로 변경. a¹값이 달라지므로 ∂L/∂W² 결과도 달라짐. 역전파 공식 ∂L/∂W² = (∂L/∂ŷ)·a¹ 에서 a¹=1.0으로 계산.

Q13 [응용] 계산형 ⭐⭐⭐ 어려움 슬라이드 22
Q12와 동일한 조건에서 ∂L/∂W¹을 계산하면?
x=1, W¹=1.0, b¹=0, W²=0.5, b²=0, y=0 ŷ=0.5, ∂L/∂ŷ=1.0, a¹=1.0 (ReLU'=1, z¹>0)
A∂L/∂W¹ = 0.5
B∂L/∂W¹ = 1.0
C∂L/∂W¹ = 1.5
D∂L/∂W¹ = 2.0
ANSWER & SOLUTION

A — ∂L/∂W¹ = 0.5

∂L/∂W¹ = (∂L/∂ŷ) · W² · ReLU'(z¹) · x = 1.0 × 0.5 × 1 × 1 = 0.5

원본(강의)에서는 ∂L/∂W¹ = 2·2·1·1 = 4.0이었다. W²가 2→0.5로 줄었으므로 그래디언트도 1/4 수준으로 감소.

변형 포인트

W²=2→0.5로 변경이 핵심. W²가 역전파 경로에서 승수 역할을 하므로 ∂L/∂W¹이 W²에 비례하여 변한다. 이것이 Chain Rule에서 "이전 층의 그래디언트가 다음 층 가중치에 영향을 받는" 핵심 원리.

Q14 [응용] 객관식 ⭐⭐ 보통 슬라이드 16~17
깊은 네트워크에서 Sigmoid 대신 ReLU를 사용할 때 얻을 수 있는 이점으로 가장 적절하지 않은 것은?
Az > 0 구간에서 기울기가 1로 일정하여 Vanishing Gradient 문제가 완화된다
Bmax(0,z) 연산이 지수 함수보다 단순하여 계산 속도가 빠르다
C출력이 (0,1) 범위로 제한되어 확률적 해석이 용이하다
D포화 구간이 존재하지 않아(z>0) 깊은 네트워크 학습에 적합하다
ANSWER

C — 출력이 (0,1)로 제한되고 확률적 해석이 가능한 것은 Sigmoid의 특성이다. ReLU의 출력 범위는 [0, ∞)이며 확률 해석에 적합하지 않다.

변형 포인트

기본 문제(Q4)는 올바른 설명을 고르는 구조였으나, 이 문제는 "ReLU의 이점이 아닌 것"을 고르는 역방향 구조로 변형. Sigmoid와 ReLU의 특성 혼동을 유도.

Q16 [응용] OX ⭐⭐ 보통 슬라이드 17
tanh 함수는 출력이 zero-centered이고 기울기 최대값이 Sigmoid(0.25)보다 크기 때문에, 현재 딥러닝 Hidden Layer에서 ReLU보다 더 널리 사용된다.
⭕ O
❌ X
ANSWER

X (거짓) — tanh가 Sigmoid보다 개선된 것은 맞으나, 여전히 양 끝에서 포화 구간이 존재하여 깊은 네트워크에서 Vanishing Gradient 문제가 발생한다. 현재 Hidden Layer 기본은 ReLU이며, tanh는 현재 거의 사용하지 않는다.

변형 포인트

tanh의 장점(zero-centered, 기울기 최대값=1)을 사실로 제시하되, 결론(ReLU보다 널리 사용)을 거짓으로 설계. 장점을 알아도 현재 실제 사용 여부까지 알아야 풀 수 있는 구조.

Q24 [응용] 서술형 ⭐⭐⭐ 어려움 슬라이드 4~9
딥러닝 역사에서 두 번의 'AI 겨울'이 발생한 원인을 각각 설명하고, 이를 극복한 핵심 기술적 돌파구를 서술하시오.
채점 기준
1차 겨울 원인: XOR 한계 2차 겨울 원인: Vanishing Gradient 역전파(1986) AlexNet·GPU·ReLU(2012) 각 원인-돌파구 인과 대응

▸ 감점 요인: 1·2차 겨울 원인을 혼동하거나 구분 없이 나열. 역전파의 수학적 핵심(Chain Rule) 미언급. AlexNet의 핵심 기술(GPU·ReLU·Dropout) 중 2개 이상 누락.

모범 답안

1차 겨울(1970년대): Minsky & Papert가 단층 퍼셉트론(선형 모델)은 XOR 문제를 수학적으로 풀 수 없음을 증명하였다. 이로 인해 신경망에 근본적 한계가 있다는 비관론이 확산되어 연구 지원금이 삭감되었다. 돌파구는 1986년 Rumelhart·Hinton·Williams의 역전파 알고리즘으로, Chain Rule을 이용해 다층 신경망의 가중치를 효율적으로 갱신함으로써 XOR 문제를 해결하고 2차 연구 붐을 이끌었다.

2차 겨울(1990년대): 데이터 부족, 연산 속도 한계, Vanishing Gradient 문제로 깊은 신경망 학습이 어려웠고 SVM이 학계 주류로 부상하였다. 돌파구는 2012년 AlexNet으로, GPU 병렬연산·ReLU 활성화(Vanishing Gradient 완화)·Dropout·대규모 데이터를 결합하여 ImageNet에서 압도적 성능을 달성하였다.

Q25 [응용] 객관식 · 조건 변형 ⭐⭐⭐ 어려움 슬라이드 18, 22
강의 2계층 MLP 역전파 예시에서 활성화 함수를 ReLU에서 Sigmoid로 교체했을 때, ∂L/∂W¹ 계산 과정에서 달라지는 핵심 항목으로 가장 적절한 것은?

(조건: x=1, W¹=0.5, b¹=0, W²=2, y=0, z¹=0.5)
A손실 함수 L 값이 달라진다
B∂L/∂ŷ 값이 달라진다
C활성화 함수 미분값(σ'(z¹))이 ReLU'(z¹)=1에서 σ'(0.5)≈0.235로 달라져 ∂L/∂W¹이 감소한다
DW² 값이 변하여 역전파 경로가 끊긴다
ANSWER & SOLUTION

C

ReLU 사용 시: ∂L/∂W¹ = ∂L/∂ŷ · W² · ReLU'(z¹) · x = 2 · 2 · 1 · 1 = 4.0 Sigmoid 사용 시: σ'(z) = σ(z)(1-σ(z)) σ(0.5) ≈ 0.622, σ'(0.5) ≈ 0.622×0.378 ≈ 0.235 ∂L/∂W¹ = 2 · 2 · 0.235 · 1 ≈ 0.94

활성화 함수가 달라지면 역전파에서 해당 층의 미분값(σ' 또는 ReLU')이 변하며, 이것이 하위 층의 그래디언트 크기에 직접 영향을 준다. 이것이 Sigmoid의 포화 구간 문제가 Vanishing Gradient로 이어지는 메커니즘이다.

변형 포인트

원본 조건에서 활성화 함수만 ReLU→Sigmoid로 교체. 역전파 공식 구조는 동일하지만 ReLU'(z¹)=1 대신 σ'(z¹)≈0.235가 삽입되어 그래디언트가 크게 감소(4.0→0.94). Vanishing Gradient 현상을 수치로 직접 확인하는 구조.
