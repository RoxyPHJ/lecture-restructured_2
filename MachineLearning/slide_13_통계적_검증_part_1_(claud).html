13. 통계적 검증 PART 1

모델 성능을 정확하게 측정하고 검증하는 방법론
01

Accuracy만으로는 부족한 이유

클래스 불균형이 있는 상황에서 Accuracy는 오해를 부르는 지표가 될 수 있다.

클래스 불균형 예시 — 암 진단 데이터 (슬라이드 3)
데이터수비율
음성 (Negative)990명99%
양성 (Positive)10명1%
전체1,000명100%
'모두 음성'으로 예측 시 Accuracy = 990/1000 = 99% — 하지만 양성 10명을 전혀 못 잡음!
문제점
  • Accuracy만 보면 '훌륭한 모델'처럼 보임
  • FN(양성 놓침) 비용이 매우 높은 상황에서 치명적
  • 클래스 불균형이 있을 때 Accuracy는 오해를 부름
올바른 접근
  • 어떤 오류가 더 비싼가(위험한가)?
  • FN(놓침) vs FP(과잉반응) 중 무엇이 문제?
  • 목적에 맞는 평가 지표를 선택해야 함
02

혼동 행렬 (Confusion Matrix)

행: 실제 정답(Actual) / 열: 모델 예측(Predicted) — 4가지 결과 조합 (슬라이드 4)

03

Precision & Recall

Precision (정밀도)
Precision = TP / (TP + FP)

양성이라 예측한 것 중 진짜 양성 비율

예: 스팸 필터 — FP(정상→스팸) 최소화

Recall (재현율 / 민감도)
Recall = TP / (TP + FN)

실제 양성 중 모델이 맞춘 비율

예: 암 진단 — FN(양성→음성) 최소화

Precision-Recall 트레이드오프 (슬라이드 5)
  • 임계값(Threshold) ↑ → Precision ↑, Recall ↓
    확실한 것만 양성으로 분류
  • 임계값 ↓ → Recall ↑, Precision ↓
    더 많이 양성으로 분류
  • 두 지표는 반비례 관계
FN이 치명적 (암 진단, 결함 탐지) → Recall 우선
FP가 치명적 (스팸 필터, 법적 판단) → Precision 우선
04

F1-Score & F-beta Score

F1-Score — Precision과 Recall의 조화평균 (슬라이드 6)
F1 = 2 × (Precision × Recall) / (Precision + Recall) = 2TP / (2TP + FP + FN)
왜 산술평균이 아닌 조화평균(Harmonic Mean)?
PR산술평균F1 (조화평균)해석
0.90.10.500.18낮은 쪽에 강한 페널티!
0.80.80.800.80균형 잡힌 경우 동일

조화평균은 두 값 중 작은 쪽이 지배 — 불균형한 P/R 조합을 올바르게 페널티

F-beta Score — 상황에 따라 가중치 조정
F_beta = (1 + beta²) × P × R / (beta² × P + R)
beta > 1 : Recall 중시
예: 암 진단 → F2-Score (beta=2)
beta < 1 : Precision 중시
예: 스팸 필터 → beta=0.5
F1-Score는 클래스 불균형 데이터에서 Accuracy 대신 사용하는 표준 지표
05

ROC 곡선 & AUC

ROC = Receiver Operating Characteristic (슬라이드 7)
  • X축: FPR = FP/(FP+TN)
    음성을 양성으로 잘못 분류하는 비율
  • Y축: TPR = TP/(TP+FN) = Recall
    실제 양성 중 맞춘 비율
  • 임계값을 1→0으로 낮추면 좌하단 → 우상단으로 이동하며 곡선 형성
AUC = 1.0 : 완벽한 분류기 (최상)
AUC = 0.5 : 동전 던지기 수준 (무용지물)
AUC 의미: 임의의 양성/음성 쌍에서 양성에 더 높은 점수를 줄 확률
임계값과 무관하게 전반적 성능 비교 가능!
06

다중 클래스 평가 (Macro / Micro / Weighted)

예: 3-class 분류 — 고양이(1000개) / 개(50개) / 새(50개) (슬라이드 8)

Macro Average

클래스별 F1 점수를 단순 평균

(F1_cat + F1_dog + F1_bird) / 3

→ 모든 클래스를 동등하게 취급
소수 클래스 성능도 동일하게 반영

Micro Average

전체 TP/FP/FN를 합산한 후 계산

→ 샘플 수가 많은 클래스가 지배
'전체 샘플 기준 성능'을 볼 때

불균형 데이터에서 다수 클래스 중심으로 해석

Weighted Average

각 클래스의 샘플 수로 가중 평균

Σ(support_i × F1_i) / N

→ 클래스 불균형을 자연스럽게 반영
가장 자주 쓰이는 실전 방법

07

회귀 모델 평가 지표

분류와 달리 연속값을 예측하는 회귀 모델에는 별도의 평가 지표가 필요하다 (슬라이드 9)

지표수식특징
MSE (Mean Squared Error) (1/n) Σ(y − ŷ)² 이상치에 민감 — 큰 오차를 제곱으로 강조
RMSE (Root Mean Squared Error) √MSE y와 같은 단위 → 해석 편리, 이상치에 민감
MAE (Mean Absolute Error) (1/n) Σ|y − ŷ| 이상치에 덜 민감, 직관적, 중앙값 기반
R² (결정 계수) 1 − SS_res / SS_tot 1에 가까울수록 좋음, 0 = 평균 예측 수준과 동일
08

과적합 vs 과소적합 재정리

과소적합 (Underfitting)
  • 훈련 손실 높음, 검증 손실 높음
  • 모델이 너무 단순해서 패턴을 못 학습
  • 해결: 모델 복잡도 ↑, 특성 추가
  • 학습률·에포크 조정
적절한 학습 (Good Fit)
  • 훈련 손실 낮음, 검증 손실 낮음
  • 일반화 성공 — 목표 상태!
  • Early Stopping으로 유지
  • Validation 곡선이 수렴
과적합 (Overfitting)
  • 훈련 손실 ↓, 검증 손실 ↑
  • 훈련 데이터를 '암기'한 상태
  • 해결: 드롭아웃, L2 정규화
  • 데이터 증강, 모델 단순화
학습 곡선 (Learning Curve) — 에포크별 Train Loss vs Validation Loss (슬라이드 10)
⚡ Val Loss가 Train Loss보다 크게 높고 계속 상승 → 과적합 신호 → Early Stopping 적용!
09

편향-분산 트레이드오프 (Bias-Variance Tradeoff)

총 오차 분해 (슬라이드 11)
E[(y − f̂(x))²] = Bias² + Variance + Noise

(E[f̂(x)] − f(x))² + E[(f̂(x) − E[f̂(x)])²] + δ
High Bias (과소적합)
  • 단순한 모델 (선형, 얕은 트리 등)
  • 데이터의 패턴을 제대로 학습 못함
  • 훈련 & 검증 모두 성능 낮음
  • 해결: 모델 복잡도 ↑, 특성 공학
High Variance (과적합)
  • 복잡한 모델 (깊은 신경망 등)
  • 훈련 데이터를 '암기'한 상태
  • 훈련 성능 ↑, 검증 성능 ↓
  • 해결: 정규화, 드롭아웃, 데이터 증강
Bias-Variance Tradeoff 곡선
Sweet Spot: 모델 복잡도가 증가할수록 Bias ↓ Variance ↑ → 총 오차가 최소가 되는 복잡도 = 최적 모델 (Validation으로 찾아야 함)

Hold-out 검증의 한계

Hold-out: 데이터를 한 번 Train/Val로 분리하여 성능 추정 (슬라이드 12)

Hold-out의 3가지 문제
  • 문제 1 — 분리 방식에 따라 성능이 크게 달라짐
    운 좋은 분리: F1 = 0.87 / 운 나쁜 분리: F1 = 0.79 (같은 모델!)
  • 문제 2 — 소규모 데이터셋에서 극히 불안정
    N=200이면 Val=40개 → 1개 차이가 2.5% 성능 변화
  • 문제 3 — 훈련에 사용 가능한 데이터 낭비
    Val set 20%는 학습에 전혀 활용 못함
해결 방향 → 교차 검증 (Cross-Validation): 데이터를 여러 번 나누어 매번 다른 부분을 검증에 활용 → 더 안정적이고 신뢰할 수 있는 성능 추정
11

K-겹 교차 검증 (K-Fold Cross-Validation)

5-Fold 교차 검증 구조 (슬라이드 13)
장점
  • 모든 데이터를 한 번씩 검증에 활용
  • Hold-out보다 안정적
  • 최종 성능 = K번 점수의 평균 ± 표준편차
    (예: F1 = 0.84 ± 0.02)
  • K = 5 또는 K = 10이 일반적
단점
  • 학습을 K번 반복 → 계산 비용 K배
  • 대규모 모델에서 시간 비용 증가
12

Stratified K-Fold

일반 K-Fold의 문제 (슬라이드 14)

일반 K-Fold는 클래스 비율을 각 Fold에서 보장하지 않음

예: 전체 양성 10%, 음성 90% 데이터에서 → 어떤 Fold는 양성 2%, 어떤 Fold는 양성 18% → 불공정한 검증!
Stratified K-Fold 해결책

각 Fold의 클래스 비율을 원본 데이터와 동일하게 유지

→ 양성 10% 데이터라면 모든 Fold에서 양성 ≈ 10%, 음성 ≈ 90%

언제 사용하는가?
  • 클래스 불균형 데이터 (사기 탐지, 희귀 질환 진단, 결함 검출 등)
  • 분류 문제에서는 일반 K-Fold 대신 Stratified K-Fold를 기본으로 사용!
from sklearn.model_selection import StratifiedKFold
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
⚠️ 회귀 문제에는 Stratified K-Fold 불가 (연속값) → 일반 K-Fold 사용
13

Leave-One-Out & 기타 교차 검증 변형

LOOCV

K = N (전체 샘플 수)

  • 장점: 훈련 데이터 최대 활용, 편향 거의 없음
  • 단점: N번 학습 → 계산 비용 O(N²), 분산 높음
  • 소규모 데이터(N<100)에서 고려
Repeated K-Fold

K-Fold를 r번 다른 무작위 분할로 반복

  • 장점: 더 안정적인 성능 추정 (분산 ↓)
  • 단점: K×r번 학습 필요
  • 예: 5-Fold × 10회 반복 → 50번 학습
Time Series Split

시계열 데이터 전용

  • 미래 데이터를 훈련에 사용하지 않도록
  • 항상 과거 → 미래 방향으로 분할
  • Walk-forward 검증이라고도 함
권장: 분류 → Stratified 5-Fold / 시계열 → Time Series Split

Python 실습 코드

평가 지표 — scikit-learn (슬라이드 16)
from sklearn.metrics import (
    confusion_matrix, classification_report,
    precision_score, recall_score, f1_score, roc_auc_score
)
import numpy as np
from sklearn.svm import SVC

X = np.random.random((1000, 10)); X[:500] = X[:500] + 0.1
y_true = np.zeros(1000); y_true[:500] = 1

svc = SVC(kernel='rbf', C=1.0, gamma='scale', probability=True)
svc.fit(X, y_true)
y_pred = svc.predict(X)
y_prob = svc.predict_proba(X)[:, 1]

# 혼동 행렬
cm = confusion_matrix(y_true, y_pred)

# Precision / Recall / F1 한 번에 출력
print(classification_report(y_true, y_pred, target_names=['음성', '양성']))

# ROC-AUC (확률값 필요)
auc = roc_auc_score(y_true, y_prob)
print(f'AUC: {auc:.4f}')

# 다중 클래스 AUC
# roc_auc_score(..., multi_class='ovr', average='macro')
교차 검증 — scikit-learn (슬라이드 17)
from sklearn.model_selection import cross_val_score, StratifiedKFold

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(svc, X, y_true, cv=cv, scoring='f1')
print(f'F1: {scores.mean():.3f} ± {scores.std():.3f}')
주요 함수 정리
함수설명
classification_report()Precision / Recall / F1 / Support를 클래스별로 출력
roc_auc_score(y, y_prob)이진 분류 시 양성 클래스 확률(predict_proba()[:,1]) 전달
roc_auc_score(..., multi_class='ovr')다중 클래스 AUC
StratifiedKFold(n_splits=5)클래스 비율 유지 교차 검증
cross_val_score(..., scoring='f1')K번 성능 점수 반환 → mean/std 계산
