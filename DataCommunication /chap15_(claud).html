01

IEEE 802.11 개요

IEEE 802.11이란?

  • 무선 LAN에 대한 규격을 정의하는 표준
  • OSI 모델의 물리층과 데이터링크층을 포함
  • "무선 이더넷"이라고 불리기도 함
WiFi (Wireless Fidelity)
WiFi Alliance의 인증을 받은 무선 LAN 제품군. 미국 등에서는 무선 LAN과 동의어로 사용된다.

02

BSS & ESS 구조

기본 서비스 집합 (BSS)

  • 고정/이동하는 무선국 + 접근점(AP, Access Point)으로 구성
  • 애드 혹(Ad Hoc): AP 없이 구성
  • 기반구조 BSS: AP를 가진 BSS
ESS (Extended Service Set)
AP를 가진 2개 이상의 BSS로 구성.
분산 시스템이 각 BSS의 AP를 연결한다.
03

CSMA/CA 매체접근

CSMA/CA란?

충돌 회피 반송파 감지 다중 접속 (Carrier Sense Multiple Access with Collision Avoidance)

  • 무선 네트워크에서 사용 — 무선은 충돌 감지(CD)가 불가능하므로 회피(CA) 방식 채택
  • 숨겨진 지국(Hidden Station) 문제 해결
  • 구성: 프레임간 공간(IFS) + 경쟁 구간 + 확인응답(ACK)

RTS-CTS-DATA-ACK 절차

  • RTS: 송신 지국이 채널 사용 요청
  • CTS: 수신 지국이 허가 응답
  • DATA: 실제 데이터 프레임 전송
  • ACK: 수신 지국이 수신 확인
CTS 수신 후 주변 모든 지국은 NAV를 설정하여 채널 접근을 억제한다.
04

숨겨진 지국 / 노출된 지국 문제

숨겨진 지국 문제 (Hidden Station)

  • A와 C가 모두 B와 통신하려 할 때, A와 C는 서로의 신호를 감지하지 못함
  • 두 지국이 동시에 B에게 전송 → 충돌 발생
  • 해결책: RTS/CTS 핸드셰이킹

노출된 지국 문제 (Exposed Station)

  • B가 A에게 전송 중일 때, C는 B의 신호를 감지하여 전송을 억제
  • 실제로 C→D 전송은 간섭 없이 가능하지만 불필요하게 차단됨
  • → 채널 낭비 발생
05

NAV & CSMA/CA 흐름도

NAV (Network Allocation Vector)

채널 사용 여부를 확인하기 전에 대기해야 하는 시간을 나타내는 타이머.

  • CTS 수신 시 주변 지국은 NAV를 설정
  • NAV가 0이 될 때까지 채널 접근 억제 → 충돌 회피
  • 물리적 CS가 아닌 가상(Virtual) CS 메커니즘
NAV = 채널이 예약되어 있다는 신호. 실제 전파를 측정하지 않고도 충돌을 회피할 수 있게 한다.

물리층 & WiFi 세대

OFDM (직교주파수 분할 다중화)

Orthogonal Frequency Division Multiplexing — FDM과 유사하지만, 한 명의 사용자가 여러 개의 직교하는 캐리어 주파수를 이용하여 간섭을 최소화하며 전송하는 방식.

직교(Orthogonal): 각 서브 캐리어의 피크에서 나머지 서브 캐리어의 값이 0 → 상호 간섭 없음

WiFi 세대별 속도 비교

  • Wi-Fi 5 802.11ac — 433Mbps ~ 3.39Gbps
  • Wi-Fi 6 802.11ax — 1Gbps ~ 10Gbps
  • Wi-Fi 7 802.11be — 최대 46Gbps (평균 5Gbps), 4096-QAM
4096-QAM: Wi-Fi 7에서 도입. 한 심볼에 12비트 정보 인코딩 → 전송 효율 극대화
07

블루투스 개요

블루투스란?

  • 서로 다른 기능의 장치를 연결하기 위한 무선 기술
  • 표준: IEEE 802.15
  • 무선 개인 영역 네트워크(PAN)로 정의
  • 저전력에 초점
  • 전송 거리: 10m 이내 (증폭기 사용 시 100m)

버전별 발전

2004BT 2.03 Mbps
2009BT 3.024 Mbps
2010BT 4.024Mbps / 저전력 1M
2016BT 5.050Mbps / 저전력 2M · 거리 40m
2024BT 6.0위치추적 정확도 향상, 보안강화
08

Piconet & Scatternet

Piconet 구조

  • 1개의 Primary(주국) + 최대 7개의 Secondary(종국)
  • 최대 8개 장치로 구성
  • Primary가 통신 스케줄 결정
Scatternet
2개 이상의 Piconet이 연결된 구조.
하나의 장치가 두 Piconet에 동시에 참여하여 브리지 역할을 수행.
09

블루투스 계층 구조

Radio 계층

  • 인터넷 모델의 물리층과 유사
  • 적은 전력으로 10m 반경 커버
  • 2.4GHz ISM 대역 — 79개 채널, 채널당 1MHz
  • FHSS(주파수 도약 확산 스펙트럼) 사용 — 초당 1,600번 도약
FHSS: 다른 장치/네트워크의 간섭을 피하기 위해 주파수를 빠르게 변환하며 전송

Baseband 계층 & L2CAP

  • Baseband: LAN의 MAC 계층과 유사
  • TDMA-TDD 방식 사용 (반이중 양방향)
  • L2CAP (Logical Link Control and Adaptation Protocol): LAN의 LLC 부계층과 유사, 상위 프로토콜 다중화

10

TDMA 통신 방식

TDD-TDMA 방식

  • 블루투스는 TDMA-TDD (Time Division Duplex) 사용
  • 시간을 625μs의 슬롯으로 분할
  • 주국(Primary) → 짝수 슬롯 사용
  • 종국(Secondary) → 홀수 슬롯 사용
  • 종국에서 반이중(Half-Duplex) 양방향 통신 지원 (동시 전송 불가)

단일 종국 통신

Primary와 Secondary가 625μs 슬롯을 번갈아 사용.

다중 종국 통신
피코넷에 종국이 여럿인 경우, Primary가 이전 슬롯 패킷에서 다음 전송 대상 종국을 지정하면, 지정된 종국이 다음 슬롯에 응답.
