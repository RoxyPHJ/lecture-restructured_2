01

계층적 방법 개요

핵심 아이디어

계층적 방법은 단일 평탄 파티션 대신 계층적 분해(hierarchical decomposition)를 생성한다. 결과물은 다양한 레벨에서 여러 클러스터링을 지원하는 덴드로그램(dendrogram)이다.

⚠️ 핵심 한계: 병합 또는 분할이 한 번 이루어지면 일반적으로 되돌릴 수 없다 (irreversible).
Agglomerative (Bottom-Up)
  • 각 객체를 독립 클러스터로 시작
  • 가장 가까운 두 클러스터를 반복적으로 병합
  • 최종: 하나의 루트 클러스터 (또는 원하는 k개)
  • n개 객체 → 최대 n−1번 병합
Divisive (Top-Down)
  • 모든 객체를 하나의 클러스터로 시작
  • 클러스터를 반복적으로 분할
  • 각 객체가 독립되거나 원하는 수까지 분할
  • 분할 기준 · 방법 · 선택 규칙 3가지 설계 필요

02

왜 계층적 클러스터링인가

k-means의 한계 vs 계층적 클러스터링의 장점
k-means (partitioning):
단일 평탄 파티션 → 딱 k개 클러스터만 생성, 다양한 세분화 수준 불가
계층적 클러스터링:
덴드로그램 생성 → 트리를 다른 높이에서 "절단"하여 다양한 수의 클러스터 획득 가능
실제 적용 예시 (다중 세분화 필요 이유)
도메인1레벨2레벨3레벨
조직 전체 직원 임원 / 관리자 / 직원 직원 내: 수석/일반/수습
필기 인식 모든 샘플 숫자별 (0~9) "7" 내: 가로선 있음/없음
계층의 두 가지 관점 (Two Viewpoints)

① 표현/요약 도구로서의 계층

  • 데이터가 본래 계층 구조를 가진다고 가정하지 않음
  • 데이터를 시각화·요약하기 위한 편의적 구조
  • 예: HR 분석에서 레벨별 평균 급여 계산

② 발견해야 할 내재 구조로서의 계층

  • 데이터에 본래 계층 구조가 존재한다고 가정
  • 그 구조를 복원하는 것이 목적
  • 예: 진화생물학 — 계통수(phylogenetic tree) 복원
  • 예: 전략 게임 — 계층적 전략 패턴 발견

병합 클러스터링 — 링케이지 측도

4가지 링케이지 측도 (Linkage Measures)

Ci, Cj: 두 클러스터  |  p, p': 각 클러스터의 객체  |  mi: Ci의 평균(centroid)  |  ni: Ci의 객체 수

이름수식별칭특징
최솟값 거리
Single		 dist_min(Ci,Cj) = min{‖p−p'‖} Nearest-neighbor 지역적 근접성 기반, 체인 효과(chaining) 발생 가능
최댓값 거리
Complete		 dist_max(Ci,Cj) = max{‖p−p'‖} Farthest-neighbor 전역적 밀착성 기반, 조밀하고 작은 클러스터 선호
평균 거리
Mean		 dist_mean(Ci,Cj) = ‖mi − mj‖ Centroid linkage 단순·효율적, 구형 클러스터에 적합
평균 쌍 거리
Average		 dist_avg = (1/ni·nj) Σ ‖p−p'‖ UPGMA 최솟값·최댓값의 절충, 범주형 데이터에도 적용 가능
예제 계산 — Cluster A: {(1,1),(2,1)} | Cluster B: {(5,1),(6,1)}
A1=(1,1), A2=(2,1) B1=(5,1), B2=(6,1) Single = dist(A2, B1) = |5-2| = 3 Complete = dist(A1, B2) = |6-1| = 5 Mean = ‖(1.5,1)−(5.5,1)‖ = 4 Average = (3+4+4+5)/4 = 4
링케이지 해석 및 아웃라이어 민감도
링케이지클러스터 선호아웃라이어 영향비고
Single느슨한 클러스터, 긴 체인 허용하나의 이상점이 두 클러스터를 연결체인 효과(chaining)
Complete조밀하고 작은 클러스터먼 이상점이 거리를 크게 부풀림구형 클러스터에 유리
Mean구형 클러스터비교적 안정비볼록(non-convex)에 부적합
Average균형 잡힌 클러스터가장 안정적범주형 데이터 적용 가능
✅ Mean distance · Average distance는 극단적 쌍 거리의 영향을 줄여 더 안정적인 절충안으로 간주됨

Ward's Method & 파티셔닝 연결성

파티셔닝과 계층적 클러스터링의 연결

파티셔닝 방법은 SSE (Sum of Squared Errors)를 사용하여 클러스터 품질 평가. n개 점을 n개 클러스터로 분할하면 각 점이 독립 클러스터 → 이것이 바로 병합 클러스터링의 출발점.

핵심 휴리스틱: 어떤 두 클러스터를 병합해야 하는가?
→ 병합 후 SSE 증가가 가장 작은 쌍을 선택 (클러스터를 최대한 조밀하게 유지)
Ward's Method

두 클러스터를 병합했을 때 총 within-cluster SSE 증가량을 측도로 사용. 증가량이 가장 작은 쌍이 가장 유사하다고 판단.

W(Ci, Cj) = [Σ ‖x − m(ij)‖²] − [Σ ‖x − mi‖² + Σ ‖x − mj‖²] = (ni · nj)/(ni + nj) · ‖mi − mj‖² = 클러스터 크기 × 두 centroid 간 거리² (조화평균 가중)
해석: 두 클러스터는 병합 시 within-cluster variance 증가가 최소인 경우 병합한다.
→ centroid가 가깝고 크기도 고려 → 조밀하고 저분산 클러스터 보존 (Greedy)

분할 클러스터링 — 3가지 핵심 이슈

분할(Divisive) 방법 설계 시 답해야 할 3가지 질문
Issue 1: 분할 기준

어떻게 더 나은 분할을 평가하는가?

  • 수치형: SSE (낮을수록 조밀)
  • 범주형: Gini 지수
  • 같은 수의 클러스터 → 더 작은 SSE 선택
Issue 2: 분할 방법

실제로 어떻게 분할하는가?

  • 전수 탐색은 계산 불가능
  • Bisecting k-means: k=2로 k-means 실행
  • 전역 최적 보장 ✗, 효율적·실용적 ✓
Issue 3: 다음 분할 클러스터 선택

어떤 클러스터를 다음에 분할하는가?

  • "가장 느슨한" 클러스터 선택
  • 평균 SSE가 가장 큰 클러스터:
E(Ci) = (1/|Ci|) Σ ‖x − mi‖²

내부 분산이 가장 큰 클러스터가 분할로 가장 큰 이득을 얻음

BIRCH — CF & CF-Tree

BIRCH 탄생 배경 — 기존 방법의 한계
① 비가역성 (Irreversibility)
한 번의 병합/분할 결정을 되돌릴 수 없음. 초기 잘못된 결정이 전체 품질 저하.
② 확장성 부족 (Poor Scalability)
각 단계에서 많은 옵션 검토 → 대용량 데이터에서 시간·공간 비용이 급증.
BIRCH: Balanced Iterative Reducing and Clustering using Hierarchies
→ CF-Tree라는 컴팩트 요약 구조를 통해 대규모 데이터를 효율적으로 클러스터링
Clustering Feature (CF): 컴팩트 클러스터 요약

d차원 공간의 n개 데이터 포인트로 구성된 클러스터를 3가지 통계량으로 요약:

CF = ⟨n, LS, SS⟩ n = 클러스터 내 포인트 수 LS = 선형 합 = Σ xi (각 차원별) SS = 제곱 합 = Σ ‖xi‖² → n개 원시 포인트 대신 상수 크기의 CF만 저장!
Centroid: x0 = LS/n Radius R = √(SS/n − (‖LS‖/n)²) = centroid까지 평균 거리 Diameter D = √((2n·SS − 2‖LS‖²) / (n(n−1))) = 평균 쌍 거리 R, D 모두 클러스터의 '조밀도(tightness)' 측정
CF 가산성 (Additivity) — 핵심 성질

두 서로소(disjoint) 클러스터 C₁, C₂에 대해:

CF₁ + CF₂ = ⟨n₁+n₂, LS₁+LS₂, SS₁+SS₂⟩ → 원본 데이터 없이 두 CF만으로 병합 클러스터의 CF 계산 가능!
예제:
C₁ = {(2,5),(3,2),(4,3)} → CF₁ = ⟨3, (9,10), 67⟩
C₂ = disjoint → CF₂ = ⟨3, (35,36), 857⟩
C₃ = C₁∪C₂ → CF₃ = ⟨6, (44,46), 924⟩ (계산 확인: 3+3=6, 9+35=44, 67+857=924)

BIRCH — 2단계 알고리즘

Phase 1: CF-Tree 구축 (Microclustering)
  • 데이터베이스를 스캔하며 인메모리 CF-Tree 점진적 구축
  • 인접한 데이터 포인트들을 마이크로클러스터로 그룹화
  • 각 마이크로클러스터는 CF(n, LS, SS)로 압축 표현
  • 새 포인트 → 가장 가까운 마이크로클러스터에 흡수 시도
  • 임계값(T) 초과 시 새 잎 엔트리 생성
  • 잎 노드 용량 초과 시 → 분할 → 상위 전파 (height-balanced 유지)
결과: 수백만 원시 포인트 → 훨씬 적은 수의 압축 마이크로클러스터
Phase 2: 전역 클러스터링 (Macroclustering)
  • CF-Tree의 잎 엔트리(마이크로클러스터)에 클러스터링 알고리즘 적용
  • 원본 데이터 재방문 없이 압축된 잎 엔트리만 처리
  • 적용 가능: k-means, 병합 클러스터링 등 다양한 방법
  • 아웃라이어 제거 + 클러스터 병합으로 결과 정제
  • 선택적 정제 단계: 포인트 재할당으로 정확도 향상
결과: 마이크로클러스터에서 의미 있는 고수준 클러스터 구조 생성
BIRCH 특징 및 한계

장점

  • 시간 복잡도 O(n) — 선형 확장성
  • 점진적(incremental) 클러스터링 지원
  • CF 요약으로 메모리 사용 대폭 감소
  • 다단계 정제 가능

한계

  • CF-Tree 노드가 항상 "자연스러운" 클러스터와 대응하지 않음
  • 반경/지름으로 경계 제어 → 구형 클러스터 가정
  • 비구형·고신장형 클러스터에서 성능 저하
  • 수치형 데이터에 최적화 (범주형에 덜 적합)

밀도 기반 방법 & DBSCAN

밀도 기반 방법의 동기
파티셔닝 방법의 한계:
거리 기반 → 구형 클러스터에는 좋지만, 임의 형태 클러스터에 취약. 아웃라이어를 클러스터로 강제 할당.
밀도 기반 방법의 장점:
로컬 밀도가 충분히 높은 영역을 클러스터로 정의 → 임의 형태 발견 가능, 아웃라이어 자연스럽게 식별.
DBSCAN 핵심 개념 — 파라미터 및 포인트 유형

두 파라미터:

  • ε (epsilon): 이웃 반경 (neighborhood radius)
  • MinPts: 조밀 영역 형성을 위한 최소 포인트 수

세 가지 포인트 유형:

Core Point: ε-이웃에 MinPts 이상의 포인트 존재 → 클러스터 시작 가능
Border Point: Core가 아니지만 어떤 Core 포인트의 ε-이웃에 속함
Noise (Outlier): 어떤 Core 포인트의 이웃에도 속하지 않음
DBSCAN 알고리즘 수도코드
Input: D (데이터셋), ε (반경), MinPts (최소 포인트) Output: 밀도 기반 클러스터 집합 (1) 모든 객체를 unvisited로 표시 (2) do (3) 무작위로 unvisited 객체 p 선택 (4) p를 visited로 표시 (5) if p의 ε-이웃에 MinPts 이상 포인트 존재: (6) 새 클러스터 C 생성, p를 C에 추가 (7) N = p의 ε-이웃 객체 집합 (8) for each p' in N: (9) if p'가 unvisited: (10) p'를 visited로 표시 (11) if p'의 ε-이웃 ≥ MinPts → N에 해당 포인트 추가; p'를 C에 추가 (12) end for (13) C 출력 (14) else p를 noise로 표시 (15) until unvisited 객체 없음

클러스터링 품질 측정

내재적 방법 (Intrinsic Methods)

정답 레이블(ground truth)이 없을 때 사용. 클러스터링의 두 가지 핵심 직관에 기반:

Intra-cluster Cohesion: 같은 클러스터 내 포인트들이 얼마나 조밀한가
Inter-cluster Separation: 서로 다른 클러스터들이 얼마나 잘 분리되어 있는가
Dunn Index (DI)

클러스터 조밀도와 분리도를 하나의 비율로 결합:

Δ = max{d(oi, oj) : C(oi) = C(oj)} 같은 클러스터 내 최대 거리 (worst-case 지름) δ = min{d(oi, oj) : C(oi) ≠ C(oj)} 다른 클러스터 간 최소 거리 (closest pair) DI = δ / Δ DI ↑ : 클러스터가 서로 멀고 내부는 조밀 → 좋은 클러스터링 DI ↓ : 클러스터가 가깝거나 내부가 느슨 → 나쁜 클러스터링 ⚠️ 극단 거리(δ, Δ) 사용 → 아웃라이어에 민감
Silhouette Coefficient (실루엣 계수)

각 객체 o에 대해 두 가지 값을 계산:

a(o) = 같은 클러스터 내 다른 모든 객체까지의 평균 거리 = Σ dist(o,o') / (|Ci| - 1) [응집도: 낮을수록 좋음] b(o) = 가장 가까운 다른 클러스터의 평균 거리의 최솟값 = min over Cj≠Ci { Σ dist(o,o') / |Cj| } [분리도: 높을수록 좋음] s(o) = (b(o) - a(o)) / max{a(o), b(o)} ∈ [-1, 1]

계산 단위전체 클러스터링개별 포인트 → 평균 가능
아웃라이어 민감도높음 (극단 거리 사용)낮음 (평균 거리 사용)
