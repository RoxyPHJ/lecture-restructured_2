01

차원 축소 개요

Slide 2
Dimensionality Reduction이란?

많은 실세계 데이터셋은 이미지, 텍스트, 생체 신호, 센서 데이터처럼 매우 많은 수의 feature로 기술됩니다.

하지만 관측 차원은 데이터의 내재적 복잡도(intrinsic complexity)보다 큰 경우가 대부분입니다.

  • 일부 변수는 중복(redundant)되거나 서로 높은 상관관계를 가짐
  • 일부 변수는 유용한 구조보다 노이즈를 주로 기여함

차원 축소는 원래의 고차원 표현을 저차원으로 대체하는 방법을 연구합니다. 데이터의 가장 중요한 구조를 보존(preserving)하면서 말이죠.

활용 목적
  • 데이터 압축 (compression)
  • 시각화 (visualization)
  • 잡음 제거 (denoising)
  • 전처리 단계 (preprocessing)
대표 고차원 데이터
  • 이미지 → 픽셀 값 (고차원)
  • 텍스트 → Word/Token features
  • 생체 신호 → Gene expression, EEG
  • 센서 → IoT 시계열 features
고차원 → 저차원 표현 개념도
02

고차원 데이터의 문제: 차원의 저주

Slide 3
Curse of Dimensionality

고차원 공간은 저차원 공간과 매우 다르게 동작합니다. 차원이 증가할수록 공간의 부피가 급격히 커지고, 데이터 포인트는 그 공간을 매우 희소하게(sparsely) 채웁니다.

차원 증가에 따른 공간 희소성
통계적 문제

희소성으로 인해 많은 통계적 추정이 불신뢰해지고, 학습 알고리즘은 동일한 성능을 달성하기 위해 훨씬 더 많은 훈련 샘플이 필요해집니다.

거리 기반 문제

고차원에서는 거리 기반 직관이 약해집니다. 가까운 포인트와 먼 포인트를 구별하기 어려워져 클러스터링, 최근접 이웃(k-NN) 등의 기하 알고리즘에 악영향을 미칩니다.

03

두 가지 접근 방식

Slide 4
구분 Feature Selection Feature Extraction
핵심 개념 원본 변수의 부분집합 유지 원본 변수로부터 새 변수 생성
원본 변수 원본 변수 그대로 사용 선형 결합 등으로 변환
해석 가능성 높음 (원본 변수 유지) 낮을 수 있음 (새 변수 생성)
예시 Lasso, Filter, Wrapper 방법 PCA, LDA, Autoencoder
출력 변수 원본 변수의 부분집합 (x₁, x₃, x₅…) 새로운 직교 변수 (PC1, PC2…)
PCA는 Feature Extraction에 속함

PCA는 서로 상관된(correlated) 원본 변수들을 더 작은 수의 새로운 직교(orthogonal) 변수들로 변환합니다. 이 새로운 변수들을 주성분(principal components)이라고 합니다.

04

PCA 개요 및 특성

Slide 5
왜 PCA인가?
  • 수학적으로 단순(simple)하고 계산이 효율적(efficient)
  • 다양한 도메인에 폭넓게 적용 가능
  • 데이터의 중요한 방향을 원칙적으로 식별하는 방법 제공
  • 가장 중요한 방향만 유지하여 정보 손실이 비교적 작은 압축 표현 생성
  • 비상관(decorrelated) features 생성 → 이후 분석/모델링 단순화
  • ML·DM에서 차원 축소의 1순위 접근법
★ 중요 개념: Decorrelated vs. Independent
비상관(decorrelated): X와 Y 사이에 선형 관계가 없음 → Cov(X,Y) = 0
독립(independent): X와 Y 사이에 어떤 종류의 의존성도 없음 → p(x,y) = p(x)·p(y)

독립 → 비상관 (O)  |  비상관 → 독립 (X, 일반적으로 성립 안 함)
PCA는 decorrelated features를 만들지만 독립을 보장하지는 않습니다.
05

직관에서 정식화로

Slide 6
핵심 질문

PCA는 저차원 선형 표현을 찾는 문제로 정식화됩니다. 핵심 질문은: "투영된 데이터가 가능한 한 많은 구조를 보존하도록 어떤 방향을 선택해야 하는가?"

PCA는 투영 분산이 최대화되는 방향을 선택함으로써 이에 답합니다.

분산 크기와 정보 보존
  • 큰 분산 방향: 데이터의 spread와 상대적 배치 보존 → 포인트들이 구별됨 (High signal)
  • 작은 분산 방향: 포인트들을 한데 뭉침 → 유용한 구조 손실 (Data collapse)

Ref: Shlens 2014, A Tutorial on PCA

06

데이터 표현 (Data Representation)

Slide 7
중심화 (Centering)

x₁, x₂, …, xₙ ∈ ℝᵈ 를 중심화된(centered) 데이터 포인트라 합니다. 중심화는 표본 평균을 0으로 이동시킨다는 의미입니다.

x̄ = (1/n) Σᵢ xᵢ     xᵢ ← xᵢ − x̄
표본 평균 계산 후, 각 데이터에서 빼기

PCA는 데이터가 평균 주위에서 어떻게 변하는지에 집중합니다. 그래서 먼저 centering이 필요합니다.

단위 벡터로의 투영

PCA는 데이터가 투영될 단위 벡터 w ∈ ℝᵈ를 탐색합니다.

y = wᵀx,    ||w|| = 1
샘플 x의 1차원 투영값 y
  • PCA는 각 고차원 샘플을 방향 w 위로의 투영으로 표현
  • 핵심 문제: 투영된 데이터가 최대한 많은 변동을 보존하도록 w 선택
07

투영 분산 (Projection Variance)

Slide 8
공분산 행렬 (Covariance Matrix)

중심화된 데이터에 대해, 공분산 행렬 Σ는 변수들이 데이터셋 전체에서 어떻게 함께 변하는지를 요약합니다.

Σ = (1/n) Σᵢ xᵢxᵢᵀ
투영 분산 공식

방향 w에 대해 샘플 x의 투영은 y = wᵀx이며, 이 1차원 투영의 분산은:

Var(wᵀx) = wᵀΣw
투영 방향 w에서 보존되는 데이터 분산의 양

양 wᵀΣw는 투영 방향 w를 따라 얼마나 많은 데이터 분산이 보존되는지를 측정합니다.

08

PCA 목적함수 (Objective)

Slide 9
제1 주성분 정의

제1 주성분(First Principal Component)은 투영된 데이터의 분산이 가장 큰 방향으로 정의됩니다.

PCA는 wᵀΣw를 최대화하는 방향 w를 찾습니다. PCA는 w의 방향에만 관심이 있으므로(크기 무관), 크기 제약 조건을 부여합니다.

제약 조건 필요 이유: 제약이 없으면 w를 단순히 스케일링하는 것만으로 목적함수 값을 무한히 크게 만들 수 있음 → ||w|| = 1 제약으로 방향만 최적화
maxw wᵀΣw     subject to ||w|| = 1
PCA 최적화 문제 (제1 주성분)
09

최적화 → 고유벡터 유도

Slide 10
라그랑지안 (Lagrangian) 구성

제약 최적화 문제를 풀기 위해 Lagrange multiplier λ를 사용하여 라그랑지안을 구성합니다.

L(w, λ) = wᵀΣw − λ(wᵀw − 1)
1계 조건 (First-Order Condition)

w에 대해 미분하고 0으로 놓으면:

∇wL = 2Σw − 2λw = 0  ⟹  Σw = λw
공분산 행렬의 고유값 방정식 (Eigenvalue Equation)
  • 최적 방향 w는 공분산 행렬 Σ의 고유벡터(eigenvector)이어야 함
  • 연관된 고유값(eigenvalue) λ는 그 방향에서 포착된 분산의 양을 측정
  • 더 큰 고유값 = 더 많은 정보를 담은 방향
10

다중 주성분 (Multiple PCs)

Slide 11
순차적 주성분 구성
  • 제1 PC: 데이터에서 가장 큰 분산을 포착
  • 제2 PC: 제1 PC에 직교(orthogonal)하는 조건 하에서, 남은 분산 중 가장 큰 것 포착
  • 제k PC: 이전 모든 PC에 직교하면서 추가적 분산을 최대로 포착
k차원 PCA 표현

일반적으로 PCA는 직교 정규 방향들의 시퀀스 u₁, u₂, …, uₐ를 구성합니다. k차원 PCA 표현은 각 데이터 포인트를 처음 k개의 주성분에 투영하여 얻습니다.

W = [u₁, u₂, …, uₖ],    z = Wᵀx
투영 행렬 W (d×k) 와 저차원 표현 z (k차원)
주성분의 직교성 시각화
11

설명된 분산 (Explained Variance)

Slide 12
누적 설명 분산 비율

각 주성분은 공분산 행렬의 고유벡터이며, 그 고유값은 해당 방향에서 설명되는 분산을 나타냅니다. 큰 고유값 = 더 정보량이 많은 방향.

Explained Variance Ratio = (λ₁ + λ₂ + … + λₖ) / (λ₁ + λ₂ + … + λₐ)
처음 k개의 PC로 전체 분산 중 몇 %를 설명하는가

이 비율이 보유할 주성분 수(k)를 결정하는 데 사용됩니다. 일반적으로 누적 설명 분산이 85~95%가 되도록 k를 선택합니다.

Scree Plot (누적 설명 분산 비율 예시)

PCA 차원 축소 수식 절차

Slide 13
기호 정의
  • x ∈ ℝᵈ: 원본 데이터 벡터, μ: 데이터셋의 평균
  • x̂ = x − μ: 중심화된 데이터 벡터
  • Uₖ = [u₁, u₂, …, uₖ] ∈ ℝᵈˣᵏ: 공분산 행렬의 상위 k개 고유벡터 (가장 큰 고유값에 대응)
  • z = Uₖᵀx̂ ∈ ℝᵏ: 주부분공간에 투영된 저차원 표현
투영 (Projection)
x̂ = x − μ
z = Uₖᵀx̂ ∈ ℝᵏ

원본 d차원 → k차원으로 압축

재구성 (Reconstruction)
x̃ = Uₖz + μ

버려진 고유값이 작을수록 재구성 오차도 작음 → 대부분의 분산 보존

13

PCA 실습 절차 (5단계)

Slide 14
01
데이터 중심화 (Centering)
각 관측치에서 표본 평균을 빼어 데이터를 중심화합니다. x̂ᵢ = xᵢ − x̄
02
공분산 행렬 계산
중심화된 데이터의 공분산 행렬 Σ = (1/n)XᵀX 를 계산합니다.
03
고유값 분해 (Eigendecomposition)
공분산 행렬의 고유값(eigenvalues)과 고유벡터(eigenvectors)를 구합니다. Σw = λw
04
고유값 내림차순 정렬
고유값을 내림차순으로 정렬하고, 대응하는 고유벡터도 같은 순서로 배열합니다.
05
상위 k개 선택 및 투영
상위 k개의 고유벡터를 선택하고 데이터를 해당 부분공간에 투영합니다. z = Uₖᵀx̂

PCA 예제 (2D → 1D)

Slide 15–17
예제 데이터
포인트원본 x₁원본 x₂중심화 x₁'중심화 x₂'
x₁22−1−1
x₂3300
x₃4411
μ[3, 3]ᵀ—
공분산 행렬 계산 (표본 공분산)
S = (1/(n−1)) XᵀX = (1/2) · [[2,2],[2,2]] = [[1,1],[1,1]]
고유값 & 고유벡터
λ₁ = 2,   u₁ = (1/√2)[1, 1]ᵀ
λ₂ = 0,   u₂ = (1/√2)[1, −1]ᵀ
  • 제1 PC: [1, 1]ᵀ 방향 (대각선)
  • 제2 PC: [1, −1]ᵀ 방향 (직교)
  • λ₂ = 0: 두 번째 방향에 분산 없음 → 모든 분산이 PC1에 집중
1D 투영 결과
zᵢ = xᵢ'ᵀ u₁
z₁ = −√2,   z₂ = 0,   z₃ = √2

원래 2D 데이터가 1D 좌표 (−√2, 0, √2) 로 요약됩니다.

예제 시각화: 2D → 1D 투영
재구성 (Reconstruction)
x̃ᵢ = zᵢ · u₁  (중심화 재구성)
x̃ᵢoriginal = x̃ᵢ + μ  (원본 좌표계 복원)

이 예제에서 모든 분산이 PC1에 있으므로 (λ₂=0), 재구성 오차가 0입니다. 즉, 1D 표현으로 원본을 완벽하게 복원할 수 있습니다.
