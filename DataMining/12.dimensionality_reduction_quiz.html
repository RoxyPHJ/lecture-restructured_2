Q02
객관식 기본 ⭐⭐ 보통 Slide 4

정답
B
Feature Selection은 원본 변수의 부분집합을 유지하고, Feature Extraction은 원본 변수로부터 새 변수를 구성합니다. PCA는 원본의 상관된 변수들을 더 작은 수의 직교(orthogonal) 변수인 주성분(PC)으로 변환하므로 Feature Extraction에 해당합니다.
Q03
OX 기본 ⭐ 쉬움 Slide 5
PCA가 생성하는 주성분(principal components)은 서로 비상관(decorrelated)이며, 이는 곧 서로 독립(independent)임을 의미한다.
정답
X (거짓)
비상관(decorrelated)과 독립(independent)은 다른 개념입니다. 비상관은 선형 관계가 없음(Cov(X,Y)=0)을 의미하지만, 독립은 어떤 종류의 의존성도 없음(p(x,y)=p(x)p(y))을 의미합니다. 독립 → 비상관은 성립하지만, 비상관 → 독립은 일반적으로 성립하지 않습니다. PCA는 선형 비상관을 보장하지만 통계적 독립을 보장하지는 않습니다.
Q04
단답형 기본 ⭐⭐ 보통 Slide 3
고차원 데이터에서 차원이 증가함에 따라 데이터 포인트가 공간을 매우 희소하게 채우고, 거리 기반 방법의 신뢰도가 떨어지며, 통계 추정이 불안정해지는 현상을 통칭하는 용어를 쓰시오.
정답
차원의 저주 (Curse of Dimensionality)
고차원에서는 공간의 부피가 급격히 커져 데이터가 희소해지고, 가까운 포인트와 먼 포인트의 거리 구별이 어려워집니다. 이로 인해 통계적 추정 신뢰도가 낮아지고 학습 알고리즘은 같은 성능을 위해 더 많은 훈련 샘플을 필요로 합니다.

PCA의 목적함수와 공분산 행렬에 대한 설명 중 옳지 않은 것은?

C

PCA에서 제1 주성분과 제2 주성분은 서로 직교(orthogonal)한다.
정답
O (참)
PCA는 직교 정규(orthonormal) 방향들의 시퀀스를 구성합니다. 제2 주성분은 "제1 주성분에 직교하는 조건 하에서 남은 분산 중 가장 큰 방향"으로 정의되므로, 두 주성분은 반드시 직교합니다.
Q08
단답형 기본 ⭐⭐ 보통 Slide 12
처음 k개의 주성분이 전체 분산 중 얼마나 설명하는지를 나타내는 비율의 공식을 고유값(λ)을 이용하여 쓰시오. (고유값을 내림차순 정렬했을 때 λ₁ ≥ λ₂ ≥ … ≥ λd 로 표기)
정답
(λ₁ + λ₂ + … + λₖ) / (λ₁ + λ₂ + … + λd)
각 주성분의 고유값은 그 방향에서 설명되는 분산의 양을 나타냅니다. 이 비율이 클수록 적은 수의 주성분으로 더 많은 정보를 보존합니다. 일반적으로 누적 비율이 85~95%가 되는 k를 선택합니다.

코드완성 기본 ⭐⭐ 보통 Slide 14
아래는 sklearn을 이용한 PCA 5단계 절차 코드이다. 빈칸 (A), (B), (C)에 들어갈 올바른 내용을 고르시오.
import numpy as np from sklearn.decomposition import PCA X = np.array([[2,2],[3,3],[4,4]], dtype=float) # Step 1: (A) X_centered = X - X.mean(axis=0) # Step 2–4: 공분산 행렬 계산 + 고유값 분해 + 정렬 pca = PCA(n_components=(B)) pca.fit(X_centered) # Step 5: 투영 Z = pca.(C)(X_centered)
정답
B — (A) 중심화 / (B) 1 / (C) transform
(A): 평균을 빼는 작업은 centering(중심화)입니다. 정규화(normalization)는 범위 조정, 표준화(standardization)는 평균 0 + 분산 1로 스케일까지 조정하는 것으로 다릅니다.
(B): 예제 데이터는 2D이지만 모든 분산이 PC1에 집중되므로 n_components=1이 적합합니다.
(C): fit()으로 학습된 모델에 데이터를 투영할 때는 transform()을 사용합니다. fit_transform()은 fit과 transform을 동시에 수행합니다.
Q10
객관식 기본 ⭐⭐ 보통 Slide 10
PCA에서 라그랑지안 L(w,λ) = wTΣw − λ(wTw − 1)을 w에 대해 미분하여 0으로 놓으면 도출되는 식은?
정답
C — Σw = λw
∇ₓL = 2Σw − 2λw = 0 → Σw = λw. 이것이 바로 공분산 행렬의 고유값 방정식(eigenvalue equation)입니다. 즉, 최적 방향 w는 반드시 Σ의 고유벡터(eigenvector)이어야 하고, 연관 고유값 λ는 그 방향에서 포착된 분산의 크기를 의미합니다.

계산형 [응용] 수치변형 ⭐⭐⭐ 어려움 Slide 15–16
다음 3개의 2D 데이터 포인트에 대해 PCA를 수행하려 한다.

x₁=[1, 3],   x₂=[3, 7],   x₃=[5, 11]

표본 공분산 행렬 S = (1/(n−1))XᵀX (중심화 후)를 계산했을 때, 고유값 λ₁, λ₂ 로 올바른 것은?
힌트: μ = [(1+3+5)/3, (3+7+11)/3] = [3, 7] 중심화: x₁' = [-2, -4] x₂' = [0, 0] x₃' = [2, 4] X = [[-2,-4],[0,0],[2,4]] XᵀX = ? → S = XᵀX / (n-1)
정답 및 풀이
C — λ₁ = 20, λ₂ = 0
XᵀX = [(-2)²+(0)²+(2)², (-2)(−4)+(0)(0)+(2)(4); (−4)(−2)+…, (−4)²+(0)²+(4)²]
= [[8, 16],[16, 32]]
S = XᵀX / (n−1) = [[8,16],[16,32]] / 2 = [[4, 8],[8, 16]]

고유값 방정식: det(S − λI) = 0
(4−λ)(16−λ) − 64 = 0
λ² − 20λ + 64 − 64 = 0
λ(λ − 20) = 0 → λ₁ = 20, λ₂ = 0

강의 예제와 동일하게 세 점이 완전히 공선(collinear)이므로 PC1 하나에 모든 분산이 집중됩니다.
적용된 개념
강의 예제(x=[2,2],[3,3],[4,4])와 동일한 패턴(y=2x 직선 위의 점)이지만 수치를 변형. 완전 공선 데이터는 항상 λ₂=0 → 1D로 무손실 표현 가능

객관식 [응용] 수치변형 ⭐⭐⭐ 어려움 Slide 17
강의 예제에서 데이터 x₁=[2,2], x₂=[3,3], x₃=[4,4]의 제1 주성분 방향 u₁ = (1/√2)[1,1]T에 대해 x₃를 투영한 결과 z₃ = √2 였다.

이제 데이터가 x=[6,6]으로 바뀌었다. 동일한 u₁ 과 동일한 평균 μ=[3,3]을 사용했을 때 z 값은?
정답 및 풀이
C — z = 3√2
x' = x − μ = [6,6] − [3,3] = [3,3]
z = u₁ᵀx' = (1/√2)[1,1]·[3,3] = (1/√2)(3+3) = 6/√2 = 3√2
적용된 개념
z = u₁ᵀ(x−μ) 공식. 중심화 먼저, 그 다음 투영. 강의 예제 x₃=[4,4] → z₃=√2와 비교하면 x=[6,6]은 평균으로부터 3배 멀어졌으므로 z도 3배가 됩니다 (3×√2 = 3√2).

OX [응용] 조건변형 ⭐⭐⭐ 어려움 Slide 13
d=100차원 데이터를 PCA로 k=2차원으로 축소할 때, 버려진 98개 고유값이 모두 0이라면 재구성 오차(reconstruction error)도 0이다.
정답
O (참)
강의자료에 명시된 대로 "버려진 고유값이 작을수록 재구성 오차도 작다". 버려진 고유값이 모두 정확히 0이라면, 해당 방향들에는 아무런 분산도 없다는 의미입니다. 따라서 그 방향을 버려도 어떤 정보도 손실되지 않으며 재구성 오차는 0이 됩니다. 강의 예제의 λ₂=0이 이 경우에 해당합니다.
적용된 개념
재구성: x̃ = Uₖz + μ. 고유값=0인 방향의 투영값은 0이므로 해당 방향을 포함하든 제외하든 결과가 동일합니다.

다음은 PCA 수행 결과이다. 빈칸 (A), (B)에 들어갈 알맞은 조합을 고르시오.

"5차원 데이터에 PCA를 적용했더니 고유값이 λ₁=8, λ₂=4, λ₃=2, λ₄=1, λ₅=1이었다. 처음 2개의 PC를 선택했을 때 누적 설명 분산 비율은 (A)이며, 이는 나머지 3개 PC의 방향으로는 전체 분산의 (B)만 남아있음을 의미한다."

Q15
종합판단 [응용] 개념결합 ⭐⭐⭐ 어려움 Slide 3–5
차원의 저주(Curse of Dimensionality)와 PCA의 관계에 대한 설명으로 옳지 않은 것은?
정답
C
PCA는 차원의 저주를 완화(alleviate)하는 도구이지, 모든 거리 기반 문제를 완전히 해소하는 것은 아닙니다. PCA는 선형 변환으로 분산이 큰 방향을 보존하지만, 비선형 구조나 복잡한 거리 문제는 다루지 못합니다. 또한 몇 개의 PC로 줄인 후에도 잔여 차원이 여전히 문제가 될 수 있습니다.
적용된 개념
Curse of Dimensionality (Slide 3) + PCA의 한계 (선형 방법). PCA는 강의자료 상 "차원 축소의 주요 전략"으로 소개되지만, 모든 문제를 완전히 해결하는 만능 해법으로는 제시되지 않습니다.

코드완성 [응용] 수치변형 ⭐⭐⭐ 어려움 Slide 13
아래 코드는 PCA로 저차원 표현 z를 얻은 후 원본 좌표로 재구성(reconstruction)하는 과정이다. 빈칸 (A), (B)에 들어갈 올바른 내용을 고르시오.
import numpy as np # 원본 데이터 X = np.array([[2,2],[3,3],[4,4]], dtype=float) mu = X.mean(axis=0) # [3, 3] X_hat = X - mu # centering # 제1 PC (단위 벡터) u1 = np.array([1,1]) / np.sqrt(2) Uk = u1.reshape(-1,1) # d×k = 2×1 # 투영 (저차원 표현) Z = X_hat @ (A) # 재구성 X_tilde_centered = (B) X_reconstructed = X_tilde_centered + mu
정답 및 풀이
B — (A) Uk / (B) Z @ Uk.T
투영: z = UₖᵀX̂ → Z = X_hat @ Uk (X̂: n×d, Uk: d×k → Z: n×k)
재구성: X̃_centered = Uₖz = Z @ UₖT (Z: n×k, UₖT: k×d → n×d)
(A): z = UₖᵀX̂를 행렬 표기로 쓰면 Z = X_hat @ Uk (전치는 이미 numpy 브로드캐스팅으로 처리됨 — Uk가 d×k이므로 X_hat(n×d) @ Uk(d×k) = Z(n×k))
(B): 재구성 공식 X̃=Uₖz → Z @ Uk.T (Z는 n×k, Uk.T는 k×d → 결과 n×d)
적용된 개념
투영 z=UₖᵀX̂ 와 재구성 X̃=Uₖz 수식을 numpy 행렬 곱 (@) 으로 정확히 대응시키는 문제입니다. 차원 추적이 핵심.
Q17
빈칸추론 [응용] 조건변형 ⭐⭐⭐ 어려움 Slide 9–10
다음 문장의 (A), (B)에 들어갈 올바른 단어 조합을 고르시오.

"PCA의 최적화 문제를 Lagrange multiplier로 풀면, 최적 방향 w는 공분산 행렬의 (A)임이 밝혀진다. 이때 연관된 (B)의 값이 클수록 그 방향에서 더 많은 분산이 포착된다."
정답
B — (A) 고유벡터 / (B) 고유값
Σw=λw에서 w가 고유벡터, λ가 고유값입니다. 목적함수 wTΣw = wT(λw) = λwTw = λ이므로, 고유값 λ 자체가 그 방향에서 포착되는 분산의 크기입니다. 따라서 가장 큰 고유값에 대응하는 고유벡터가 제1 주성분 방향이 됩니다.

C의 특이벡터/특이값은 SVD(특이값 분해)에서 사용하는 용어로, 코스 범위를 벗어납니다.
Q18
OX [응용] 역방향 ⭐⭐ 보통 Slide 7
PCA를 적용하기 전에 데이터를 중심화(centering)하지 않으면, 구해지는 주성분 방향은 데이터의 분산 구조가 아닌 원점으로부터의 거리 방향에 의해 왜곡될 수 있다.
정답
O (참)
PCA는 데이터가 평균 주위에서 어떻게 변하는지(분산 구조)에 집중합니다. 중심화하지 않으면 공분산 행렬 대신 원점 기준의 2차 모멘트 행렬을 사용하는 셈이 되어, 평균이 원점에서 멀리 떨어질수록 그 방향이 주성분으로 잡힐 수 있습니다. 이는 실제 데이터의 분산 구조와 무관한 결과입니다.
적용된 개념
강의자료: "centering means that the sample mean has been shifted to zero" + "PCA focuses on how the data vary around their mean"

Q20
객관식 [응용] 개념결합 ⭐⭐⭐ 어려움 Slide 3, 7, 11
PCA를 k=3으로 수행했을 때 누적 설명 분산 비율이 60%였다. 데이터가 500차원이고 학습 데이터가 충분하지 않아 차원의 저주 문제가 심하다면, 다음 중 가장 적절한 조치는?
정답
D
k=3으로 60%만 설명한다면 정보 손실이 너무 큽니다. 하지만 무작정 k를 늘리면 차원의 저주가 다시 심해집니다. 따라서 적절한 정보 보존(85~95%)을 달성하면서도 원본 500차원보다 충분히 작은 k를 선택하는 것이 핵심입니다. B는 누적 비율 기준만 언급하고 k가 차원 감소에 실제로 기여하는지 확인하지 않아 불완전합니다.
적용된 개념
Curse of Dimensionality 해결(Slide 3) + Cumulative Explained Variance Ratio로 k 결정(Slide 12). 두 개념을 동시에 고려해야 하는 개념결합 문제.
Q21
코드완성 [응용] 조건변형 ⭐⭐⭐ 어려움 Slide 12–13
아래 코드는 설명 분산 비율을 계산하고 누적 85% 기준으로 k를 자동 선택하는 코드이다. 빈칸 (A), (B), (C)에 들어갈 올바른 내용을 고르시오.
import numpy as np # 공분산 행렬에서 이미 고유값 분해 완료 (내림차순 정렬) eigenvalues = np.array([8.0, 4.0, 2.0, 1.0, 1.0]) # 누적 설명 분산 비율 계산 total = (A) evr = eigenvalues / total # 개별 비율 cumulative = (B) # 누적 85% 이상이 되는 최소 k 선택 k = (C) print(f"선택된 k: {k}")
정답 및 풀이
B
total = 8+4+2+1+1 = 16 → eigenvalues.sum()
evr = [0.5, 0.25, 0.125, 0.0625, 0.0625]
cumulative = np.cumsum(evr) = [0.5, 0.75, 0.875, 0.9375, 1.0]
cumulative >= 0.85 → [F, F, T, T, T]
np.argmax([F,F,T,T,T]) = 2 (0-indexed) → k = 2+1 = 3
(A): 전체 분산은 고유값의 합(sum), mean이나 max가 아닙니다.
(B): 누적합은 cumsum, 누적곱(cumprod)이 아닙니다.
(C): argmax는 0-indexed를 반환하므로 +1을 해야 개수(k)가 됩니다.
적용된 개념
Explained Variance Ratio 공식을 코드로 구현. argmax의 0-indexing과 +1 필요성이 핵심 함정.

Q25
객관식 [응용] 조건변형 ⭐⭐⭐ 어려움 Slide 8–10
2차원 데이터의 공분산 행렬이 Σ = [[5, 0],[0, 2]] 라고 하자. PCA를 적용할 때 제1 주성분 방향 u₁과 그에 대응하는 투영 분산으로 올바른 것은?
정답 및 풀이
B — u₁ = [1,0]T, 투영 분산 = 5
Σ = [[5,0],[0,2]]는 이미 대각 행렬 → 고유벡터 = 표준 기저 벡터
고유값: λ₁=5 (방향 [1,0]T), λ₂=2 (방향 [0,1]T)
제1 PC = 가장 큰 고유값 λ₁=5에 대응하는 u₁=[1,0]T
투영 분산 = u₁TΣu₁ = [1,0][[5,0],[0,2]][1,0]T = 5
공분산 행렬이 대각(diagonal)이면 고유벡터는 표준 기저 벡터, 고유값은 대각 원소입니다. A는 작은 고유값(λ₂=2)을 선택한 오답, C는 두 방향의 평균값을 선택한 오답입니다.
적용된 개념
Σw=λw에서 대각 행렬의 고유값/벡터 특성 + 투영 분산 wTΣw 계산. 조건을 대각 행렬로 바꿔 직접 연산이 단순해졌지만, 올바른 PC 선택 기준(최대 고유값)을 알아야 풀 수 있습니다.
